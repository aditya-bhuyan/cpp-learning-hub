Chapter 07 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Work through each exercise in a text editor or IDE. Compile with g++ -std=c++17 -Wall and run your program. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Circle Class Easy

Create a class Circle with a private radius. Provide a constructor, area(), circumference() and a display() method. All three query methods must be const.

Hints:

  • Use 3.14159265358979 for π (or static constexpr double PI inside the class).
  • Use fixed and setprecision(2) from <iomanip> for tidy output.

Expected output:

Circle radius 5.00
  area          = 78.54
  circumference = 31.42
Circle radius 1.00
  area          = 3.14
  circumference = 6.28
Exercise 2 — Temperature Class Easy

Create a class Temperature that stores a temperature in Celsius (private). Provide toCelsius(), toFahrenheit() and toKelvin() as const member functions.

Formulas: F = C × 9/5 + 32    K = C + 273.15

Hint: beware of integer division — 9 / 5 is 1. Write 9.0 / 5.0.

Expected output (for 100, 0 and -40 degrees C):

100.00 C = 212.00 F = 373.15 K
0.00 C = 32.00 F = 273.15 K
-40.00 C = -40.00 F = 233.15 K
Exercise 3 — Book Class Medium

Create a class Book with private members title, author, year and ISBN. Provide a constructor that uses an initialization list, a display() method and a method bool isSameAuthor(Book other) const that returns whether two books have the same author.

Hints:

  • A member function may access the private members of another object of the same class (other.author).
  • Taking Book other by value makes a copy (and calls the copy constructor). Afterwards, think about why const Book& would be better.

Expected output:

"The C++ Programming Language" by Bjarne Stroustrup (2013), ISBN 978-0321563842
"A Tour of C++" by Bjarne Stroustrup (2018), ISBN 978-0134997834
"Clean Code" by Robert C. Martin (2008), ISBN 978-0132350884
b1 and b2 same author? true
b1 and b3 same author? false
Exercise 4 — Employee Class with a Static Counter Medium

Create a class Employee with private name, id and salary. Provide raise(double percent), which increases the salary by that percentage, and display() (const).

Add a static data member that counts the total number of employees currently alive, and a static function getTotal() to read it. Increment it in the constructors and decrement it in the destructor.

Hints:

  • Define the static member outside the class: int Employee::totalEmployees = 0;
  • The copy constructor creates an object too — if you do not count it, the total will drift.
  • A 10% raise on 50000 gives 50000 + 50000 * 10 / 100.

Expected output:

Employees: 0
Employees: 2
Employee #101 Alice, salary $50000.00
Employee #101 Alice, salary $55000.00
Employee #102 Bob, salary $44310.00
Employees (inside block): 3
Employees (after block):  2
Exercise 5 — Matrix2x2 Class Hard

Create a class Matrix2x2 that stores a 2×2 matrix of double in a private 2D array. Provide:

  • a default constructor (zero matrix) and a constructor taking the four elements;
  • Matrix2x2 add(const Matrix2x2& other) const — element-wise sum;
  • Matrix2x2 multiply(const Matrix2x2& other) const — standard matrix product;
  • void display() const.

Hints:

  • Both operations return a new matrix and leave the operands unchanged — that is why they are const.
  • result[i][j] = Σk this[i][k] × other[k][j] — matrix multiplication is not commutative.
  • Chaining like A.add(B).display() works because add returns an object.

Expected output for A = [1 2; 3 4], B = [5 6; 7 8]:

A + B:
| 6  8 |
| 10  12 |
A * B:
| 19  22 |
| 43  50 |
B * A:
| 23  34 |
| 31  46 |
