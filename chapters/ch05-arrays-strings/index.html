Chapter 05 — Arrays & Strings

Store collections of values, work with text, and learn when to prefer the safer modern alternatives.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz

5.1 Arrays — Declaration and Initialization

An array is a fixed-size, contiguous block of memory holding elements of the same type. The size must be a compile-time constant. Elements are stored one after another with no gaps, which makes arrays extremely fast to traverse. 

#include <iostream>
using namespace std;

int main() {
    int a[5];                          // declared, NOT initialized (garbage values!)
    int b[5] = {10, 20, 30, 40, 50};   // size given, fully initialized
    int c[]  = {1, 2, 3};              // size deduced by the compiler: 3
    int d[5] = {1, 2};                 // remaining elements are zero: {1, 2, 0, 0, 0}
    int e[5] = {};                     // all five elements are zero
    int f[5]{};                        // C++11 brace init, also all zeros

    cout << b[0] << " " << c[2] << " " << d[4] << "\n";   // 10 3 0
    return 0;
}
Uninitialized local arrays A local array declared as int a[5]; contains indeterminate ("garbage") values. Always initialize it — int a[5] = {}; is the shortest way to get all zeros.

Zero-indexing

The first element has index 0. The index is the offset from the start of the array, so the first element is zero elements away. For an array of size n, the valid indices are 0 to n - 1.

Index01234
Value (b)1020304050

5.2 Accessing and Modifying Elements

Use the subscript operator [] to read or write an element.

int scores[4] = {70, 85, 90, 60};

cout << scores[1] << "\n";   // read  → 85
scores[3] = 75;                 // write → {70, 85, 90, 75}
scores[0] += 5;                 // compound assignment → 75
scores[2]++;                    // increment → 91

int last = scores[3];           // the last element of a 4-element array

5.3 Finding the Size — the sizeof Trick

A built-in array does not remember its own length. However, while the array is still a true array (not yet decayed to a pointer), you can compute the element count: 

int arr[] = {4, 8, 15, 16, 23, 42};

size_t totalBytes = sizeof(arr);                 // 6 × 4 = 24 bytes (assuming 4-byte int)
size_t elemBytes  = sizeof(arr[0]);              // 4 bytes
size_t count      = sizeof(arr) / sizeof(arr[0]); // 24 / 4 = 6 elements

cout << "Elements: " << count << "\n";      // Elements: 6
The trick only works in the scope where the array was declared Inside a function that receives the array as a parameter, sizeof(arr) gives the size of a pointer (typically 8 bytes), not of the array. See section 5.7. In C++17 you can use std::size(arr) from <iterator> for a safer equivalent.

5.4 Out-of-Bounds Access — Undefined Behavior

C++ does not check array indices at run time. Reading or writing outside [0, n-1] is undefined behavior (UB). 

int arr[5] = {1, 2, 3, 4, 5};

cout << arr[5];     // UB! valid indices are 0..4
arr[-1] = 99;         // UB! writes before the array
arr[100] = 7;         // UB! may corrupt other variables or crash
Undefined behavior means anything can happen The program might print garbage, crash with a segmentation fault, silently corrupt other variables, or appear to work perfectly — until the day it does not. Out-of-bounds writes are a classic source of security vulnerabilities (buffer overflows). Compile with -fsanitize=address,undefined during development to catch these bugs.

5.5 Iterating Over Arrays

Classic index-based for loop

int nums[] = {3, 6, 9, 12};
size_t n = sizeof(nums) / sizeof(nums[0]);

for (size_t i = 0; i < n; ++i) {       // note: i < n, never i <= n
    cout << "nums[" << i << "] = " << nums[i] << "\n";
}

Range-based for loop (C++11)

for (int x : nums) {          // x is a COPY of each element
    cout << x << " ";
}

for (int& x : nums) {         // x is a REFERENCE — modifications change the array
    x *= 2;                   // nums is now {6, 12, 18, 24}
}

for (const int& x : nums) {   // read-only access without copying
    cout << x << " ";
}

The range-for loop cannot go out of bounds, so prefer it whenever you do not need the index itself. It works with real arrays only — not with an array parameter that has decayed to a pointer.

5.6 Multi-Dimensional Arrays

A 2D array is an "array of arrays". Think of it as a table with rows and columns. It is declared as type name[ROWS][COLS] and accessed as name[row][col]. 

int grid[2][3] = {
    {1, 2, 3},     // row 0
    {4, 5, 6}      // row 1
};

cout << grid[0][2] << "\n";   // row 0, column 2 → 3
cout << grid[1][0] << "\n";   // row 1, column 0 → 4

grid[1][1] = 50;                // modify a single cell

// Nested loops: outer loop = rows, inner loop = columns
for (int r = 0; r < 2; ++r) {
    for (int c = 0; c < 3; ++c) {
        cout << grid[r][c] << "\t";
    }
    cout << "\n";
}

In memory, a C++ 2D array is stored in row-major order: grid[0][0], grid[0][1], grid[0][2], grid[1][0], .... Iterating with the column index in the inner loop therefore walks memory sequentially, which is cache-friendly.

col 0col 1col 2
row 0grid[0][0]grid[0][1]grid[0][2]
row 1grid[1][0]grid[1][1]grid[1][2]

5.7 Passing Arrays to Functions — Array-to-Pointer Decay

When you pass an array to a function, you do not pass a copy. The array decays to a pointer to its first element. These three declarations are identical to the compiler: 

void print(int arr[], size_t n);      // looks like an array...
void print(int arr[5], size_t n);     // ...the 5 is ignored
void print(int* arr, size_t n);       // ...all three mean int*

Because the length is lost, you must pass it as a separate parameter:

#include <iostream>
using namespace std;

void doubleAll(int arr[], size_t n) {
    // sizeof(arr) here would be sizeof(int*), NOT the array size!
    for (size_t i = 0; i < n; ++i) {
        arr[i] *= 2;              // modifies the caller's array — no copy was made
    }
}

int main() {
    int data[] = {1, 2, 3, 4};
    size_t n = sizeof(data) / sizeof(data[0]);   // compute size HERE, where data is an array

    doubleAll(data, n);

    for (int x : data) cout << x << " ";       // 2 4 6 8
    cout << "\n";
    return 0;
}

For multi-dimensional arrays, every dimension except the first must be specified: void show(int m[][3], int rows).

Protect read-only data If the function should not modify the array, declare the parameter const int arr[] (equivalently const int*). Pointers are covered in depth in Chapter 06.

5.8 C-Strings — Character Arrays

Before std::string, C represented text as an array of char terminated by the null character '\0' (value 0). The terminator is how functions know where the text ends. 

char s1[6]  = {'h', 'e', 'l', 'l', 'o', '\0'};   // explicit null terminator
char s2[6]  = "hello";    // compiler adds '\0' automatically → needs 5 + 1 = 6 bytes
char s3[]   = "hello";    // size deduced as 6
char s4[20] = "hello";    // remaining 14 bytes are all '\0'
const char* s5 = "hello"; // pointer to a read-only string literal
Index012345
s2'h''e''l''l''o''\0'

The <cstring> functions

FunctionPurposeNotes
strlen(s)Number of characters before '\0'Does not count the terminator; strlen("hello") is 5

strcat(dest, src)Append src to the end of destdest must have room for both strings plus '\0'
strcmp(a, b)Lexicographic comparisonReturns 0 if equal, <0 if a < b, >0 if a > b
 
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    char name[30];
    strcpy(name, "Ada");            // name = "Ada"
    strcat(name, " Lovelace");      // name = "Ada Lovelace"

    cout << name << "\n";
    cout << "Length: " << strlen(name) << "\n";          // 12

    if (strcmp("apple", "banana") < 0) {
        cout << "apple comes before banana\n";
    }
    // NOTE: ("apple" == "apple") would compare ADDRESSES, not text. Always use strcmp.
    return 0;
}
Buffer overflow danger strcpy and strcat perform no bounds checking. Copying a 12-character string into a char[5] overwrites adjacent memory — undefined behavior. In new code, prefer std::string.

5.9 std::string — Declaration and Initialization

std::string (header <string>) manages its own memory, grows automatically, and knows its own length. It is the right default for text in C++. 

#include <iostream>
#include <string>
using namespace std;

int main() {
    string a;                    // empty string ""
    string b = "Hello";          // from a string literal
    string c("World");           // constructor syntax
    string d(5, '*');            // "*****"  (5 copies of '*')
    string e = b;                // copy → independent string

    // Concatenation with +
    string greeting = b + ", " + c + "!";   // "Hello, World!"
    greeting += " Welcome.";                // append in place

    cout << greeting << "\n";
    return 0;
}
Literal + literal does not compile "Hello" + " World" tries to add two const char* pointers and fails. At least one operand of + must be a std::string: string("Hello") + " World".

5.10 Essential std::string Methods

MethodDescription
length() / size()Number of characters (the two are identical)
empty()true if the string has no characters

s[i]Character at index i with no bounds checking
substr(pos, len)New string of up to len characters starting at pos

#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "The quick brown fox";

    cout << s.length() << " " << s.size() << "\n";    // 19 19
    cout << boolalpha << s.empty() << "\n";           // false
    cout << s.at(4) << "\n";                          // q

    cout << s.substr(4, 5) << "\n";                   // quick
    cout << s.substr(10) << "\n";                     // brown fox  (to the end)

    size_t pos = s.find("brown");                        // 10
    if (pos != string::npos) {
        cout << "Found at index " << pos << "\n";
    }
    if (s.find("cat") == string::npos) {
        cout << "'cat' not found\n";
    }

    s.replace(4, 5, "slow");      // "The slow brown fox"
    s.erase(4, 5);                // removes "slow " → "The brown fox"
    cout << s << "\n";
    return 0;
}
Always compare find() with string::npos find returns an unsigned value. When nothing is found it returns string::npos (a very large number), not -1 and not 0. Store the result in a size_t, not an int.

5.11 String Comparison

Unlike C-strings, std::string overloads the comparison operators. They compare lexicographically (character by character using character codes), so uppercase letters sort before lowercase ones in ASCII. 

string a = "apple", b = "banana", c = "apple";

cout << boolalpha;
cout << (a == c) << "\n";     // true  — same contents
cout << (a != b) << "\n";     // true
cout << (a <  b) << "\n";     // true  — 'a' (97) < 'b' (98)
cout << (string("Zebra") < string("apple")) << "\n";   // true — 'Z' (90) < 'a' (97)
cout << (string("app") < string("apple")) << "\n";     // true — a prefix sorts first

5.12 Reading Strings with Spaces — getline()

cin >> s stops at the first whitespace, so it reads only one word. getline(cin, s) reads the entire line up to (and discarding) the newline. 

#include <iostream>
#include <string>
#include <limits>
using namespace std;

int main() {
    string word, line;

    cout << "Enter a word: ";
    cin >> word;                               // reads "Hello" from "Hello World"

    // cin >> leaves the '\n' in the buffer; discard the rest of the line
    cin.ignore(numeric_limits<streamsize>::max(), '\n');

    cout << "Enter a sentence: ";
    getline(cin, line);                          // reads the whole line, spaces included

    cout << "word = " << word << "\nline = " << line << "\n";
    return 0;
}
The classic cin / getline trap If you call getline directly after cin >> number, the leftover '\n' is consumed immediately and getline returns an empty string. Call cin.ignore(...) in between, as shown above.

5.13 Converting Between Strings and Numbers

FunctionDirectionExample
stoi(s)string → intstoi("42") → 42
stod(s)string → doublestod("3.14") → 3.14
to_string(n)number → stringto_string(99) → "99"
 
#include <iostream>
#include <string>
using namespace std;

int main() {
    int    n = stoi("42");            // 42
    double d = stod("3.14159");       // 3.14159
    string s = to_string(n + 8);      // "50"

    cout << n + 1 << "\n";             // 43   (arithmetic on a real int)
    cout << s + "!" << "\n";           // 50!  (string concatenation)

    try {
        int bad = stoi("hello");      // throws std::invalid_argument
        cout << bad;
    } catch (const invalid_argument&) {
        cout << "Not a valid integer\n";
    } catch (const out_of_range&) {
        cout << "Number too large\n";
    }
    return 0;
}

stoi and stod skip leading whitespace and stop parsing at the first invalid character (stoi("12abc") returns 12). If no conversion is possible they throw std::invalid_argument; if the value does not fit they throw std::out_of_range. Exceptions are covered in Chapter 13.

5.14 std::array<T, N> — A Safer Fixed-Size Array (C++11)

std::array (header <array>) wraps a built-in array in a class. It has the same performance and memory layout, but it knows its size, never decays to a pointer, can be copied and compared, and offers a bounds-checked at(). 

#include <iostream>
#include <array>
using namespace std;

void printAll(const array<int, 5>& a) {      // size is part of the type — no decay
    for (int x : a) cout << x << " ";
    cout << "(size " << a.size() << ")\n";    // size() works inside the function!
}

int main() {
    array<int, 5> nums = {5, 3, 8, 1, 9};

    cout << nums[0] << "\n";          // 5   — unchecked, like a C array
    cout << nums.at(4) << "\n";       // 9   — bounds-checked
    cout << nums.front() << " " << nums.back() << "\n";   // 5 9

    array<int, 5> copy = nums;        // real copy (a C array cannot be assigned like this)
    copy[0] = 100;                    // nums[0] is still 5

    printAll(nums);

    try {
        nums.at(5) = 1;               // throws std::out_of_range instead of UB
    } catch (const out_of_range& e) {
        cout << "Caught: out of range\n";
    }
    return 0;
}

If the size is not known at compile time, use std::vector (Chapter 10).

5.15 Key Takeaways

  • Arrays are fixed-size, contiguous, zero-indexed; valid indices are 0 to n-1.
  • sizeof(arr)/sizeof(arr[0]) yields the element count — only where arr is still a real array.
  • Out-of-bounds access is undefined behavior; C++ will not warn you at run time.
  • Use range-for (for (int x : arr)) when you do not need the index.
  • 2D arrays use arr[row][col] and are stored in row-major order.
  • Arrays passed to functions decay to a pointer to the first element, so pass the length separately.
  • C-strings are char arrays ended by '\0'; strlen does not count the terminator.
  • Prefer std::string over C-strings: automatic memory, +, ==, <, and rich methods.
  • find() returns string::npos when nothing is found.
  • Use getline(cin, s) for lines with spaces; convert with stoi, stod, to_string.
  • Prefer std::array<T,N> over raw arrays when the size is fixed at compile time.
