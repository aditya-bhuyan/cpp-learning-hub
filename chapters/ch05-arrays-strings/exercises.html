Chapter 05 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Work through each exercise in a text editor or IDE. Compile with g++ -std=c++17 -Wall and run your program. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Minimum, Maximum and Average Easy

Write a program that reads 10 integers into an array and prints the minimum, the maximum and the average (as a double with 2 decimal places).

Hints:

  • Initialize your min and max with the first element, not with 0 (what if every number is negative?).
  • Beware of integer division when computing the average — cast one operand to double.

Expected output (sample):

Enter 10 integers: 7 3 -2 15 8 0 9 4 11 5
Minimum : -2
Maximum : 15
Average : 6.00
Exercise 2 — Reverse an Array In-Place Easy

Write a function void reverseArray(int arr[], int n) that reverses the array in place — without declaring a second array. Test it with both an odd-length and an even-length array.

Hint: swap the first and last elements, then the second and second-to-last, and so on. How many swaps are needed for n elements?

Expected output:

Original: 1 2 3 4 5 6 7
Reversed: 7 6 5 4 3 2 1
Exercise 3 — Anagram Checker Medium

Write a function bool isAnagram(const string& a, const string& b) that returns true if the two strings contain exactly the same letters with the same frequencies, ignoring case and anything that is not a letter (spaces, punctuation).

Hint: you do not need to sort. Use an int counts[26] table as in Example 4 — add for one string, subtract for the other.

Expected output (samples):

"Listen"    and "Silent"     → are anagrams
"Dormitory" and "dirty room" → are anagrams
"hello"     and "world"      → are NOT anagrams
Exercise 4 — Rotate an Array Left by k Medium

Write a function void rotateLeft(int arr[], int n, int k) that rotates an array of n elements to the left by k positions, in place. Elements pushed off the front wrap around to the back.

Handle k >= n correctly (what should rotating 7 elements left by 10 do?).

Hint (challenge): it can be done with no extra array in O(n) time using three reversals.

Expected output (n = 7, k = 3):

Original:          1 2 3 4 5 6 7
Rotated left by 3: 4 5 6 7 1 2 3
Exercise 5 — Word Frequency Counter Hard

Read a sentence with getline and count how many times each word appears. Words should be compared ignoring case and punctuation ("The," and "the" are the same word).

Store the results in an array of structs (or two parallel arrays), for example:

struct WordCount {
    string word;
    int    count;
};
WordCount table[100];

For each word, search the table: if found, increment its count; otherwise add a new entry. Print words in the order they first appeared.

Expected output (sample):

Enter a sentence: The cat and the hat. The end, and THE start

Word frequencies:
  the : 4
  cat : 1
  and : 2
  hat : 1
  end : 1
  start : 1
