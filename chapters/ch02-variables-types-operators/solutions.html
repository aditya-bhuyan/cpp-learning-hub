Chapter 02 — Solutions

Reference solutions with explanations. Only read after attempting the exercises yourself.

Spoiler Warning These are reference solutions. There are often multiple valid approaches — if your output matches but your code differs, that is perfectly fine.
✅ Solution 1 — Sizes of the Primitive Types

Passing the variable to sizeof (rather than the type name) keeps the reported size in sync if you later change the declared type. std::setw pads each column to a fixed width and std::left left-aligns it. Sizes shown are for a typical 64-bit Linux/macOS system; on 64-bit Windows long is 4 bytes.

// solution_02_sizeof.cpp
#include <iostream>
#include <iomanip>
#include <string>    // std::string(40, '-')
using namespace std;

int main() {
    // One variable of each primitive type, all initialized
    bool        flag   = true;
    char        letter = 'C';
    short       s      = 1000;
    int         i      = 42;
    long        l      = 100000L;
    long long   ll     = 10000000000LL;
    float       f      = 3.14f;
    double      d      = 2.718281828;
    long double ld     = 1.41421356237L;
    unsigned int u     = 4000000000u;

    cout << left << setw(16) << "Type"  << setw(10) << "Bytes" << "Value\n";
    cout << string(40, '-') << '\n';

    // sizeof can take the variable itself, so the size always matches its declared type
    cout << setw(16) << "bool"         << setw(10) << sizeof(flag)   << boolalpha << flag << '\n';
    cout << setw(16) << "char"         << setw(10) << sizeof(letter) << letter << '\n';
    cout << setw(16) << "short"        << setw(10) << sizeof(s)      << s << '\n';
    cout << setw(16) << "int"          << setw(10) << sizeof(i)      << i << '\n';
    cout << setw(16) << "long"         << setw(10) << sizeof(l)      << l << '\n';
    cout << setw(16) << "long long"    << setw(10) << sizeof(ll)     << ll << '\n';
    cout << setw(16) << "float"        << setw(10) << sizeof(f)      << f << '\n';
    cout << setw(16) << "double"       << setw(10) << sizeof(d)      << d << '\n';
    cout << setw(16) << "long double"  << setw(10) << sizeof(ld)     << ld << '\n';
    cout << setw(16) << "unsigned int" << setw(10) << sizeof(u)      << u << '\n';

    return 0;
}

Sample output:

----------------------------------------
bool            1         true
char            1         C
short           2         1000
int             4         42
long            8         100000
long long       8         10000000000
float           4         3.14
double          8         2.71828
long double     8         1.41421
unsigned int    4         4000000000

Key concepts used: sizeof, <iomanip> formatting, boolalpha, variable initialization.

✅ Solution 2 — Swap Two Numbers Using XOR

XOR has two useful properties: x ^ x = 0 and x ^ 0 = x. Let the originals be A and B:

// solution_02_xor_swap.cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cout << "Enter two integers: ";
    cin >> a >> b;
    cout << "Before: a = " << a << ", b = " << b << '\n';

    // Three XORs swap the values with no temporary variable.
    // This is safe even if the VALUES are equal; it only fails if a and b are the SAME variable.
    a ^= b;   // a now holds a XOR b
    b ^= a;   // b = b XOR (a XOR b) = original a
    a ^= b;   // a = (a XOR b) XOR original a = original b

    cout << "After : a = " << a << ", b = " << b << '\n';
    return 0;
}

Sample output:

Enter two integers: Before: a = 17, b = 42
After : a = 42, b = 17
Statementab
startAB
a ^= b;A ^ BB
b ^= a;A ^ BB ^ (A ^ B) = A
a ^= b;(A ^ B) ^ A = BA
Do not use this trick in production std::swap(a, b) is clearer and just as fast on modern compilers. The XOR swap also fails when both operands are the same object (e.g. swapXor(arr[i], arr[i]) through references), because a ^= a sets it to 0.

Key concepts used: ^ and ^=, cin chaining.

✅ Solution 3 — Even or Odd with Bitwise AND

In binary, an integer's lowest bit carries the value 20 = 1; every other bit is a multiple of 2. So the number is odd exactly when that bit is set, and n & 1 isolates it. This also works for negative numbers on two's-complement machines (e.g. -3 is ...11111101, whose lowest bit is 1).

// solution_02_even_odd.cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter an integer: ";
    cin >> n;

    // The lowest bit of an odd number is 1; of an even number it is 0.
    // Parentheses are REQUIRED: == binds tighter than &.
    if ((n & 1) == 0) {
        cout << n << " is even\n";
    } else {
        cout << n << " is odd\n";
    }
    return 0;
}

Sample output:

Enter an integer: 7 is odd
Enter an integer: 10 is even
Why the parentheses matter Without them, n & 1 == 0 parses as n & (1 == 0), i.e. n & 0, which is always 0 — so every number would be reported as even.

Key concepts used: bitwise &, operator precedence (parentheses around n & 1), if/else.

✅ Solution 4 — Binary Representation of an 8-Bit Number

To read bit k of a number, shift it right by k so that the wanted bit lands in position 0, then mask with & 1. Looping k from 7 down to 0 prints the most significant bit first. Because cout would print an unsigned char as a character, value + 0 promotes it to int for the numeric label.

// solution_02_binary.cpp
#include <iostream>
using namespace std;

int main() {
    int input;
    cout << "Enter a number (0-255): ";
    cin >> input;

    if (input < 0 || input > 255) {
        cout << "Number out of range for 8 bits.\n";
        return 1;
    }

    unsigned char value = static_cast<unsigned char>(input);

    cout << value + 0 << " in binary: ";   // value + 0 promotes to int so it prints as a number
    // Visit bits from the most significant (7) down to the least significant (0)
    for (int bit = 7; bit >= 0; --bit) {
        cout << ((value >> bit) & 1);      // shift the wanted bit to position 0, mask the rest
        if (bit == 4) cout << ' ';         // nibble separator for readability
    }
    cout << '\n';
    return 0;
}

Sample output:

Enter a number (0-255): 165 in binary: 1010 0101
Enter a number (0-255): 5 in binary: 0000 0101

Trace for 165 (10100101):

bit76543210
(165 >> bit) & 110100101

Check: std::cout << std::bitset<8>(165); prints the same digits 10100101.

Key concepts used: >> and &, static_cast, for loop counting down, input validation.

✅ Solution 5 — Temperature Conversion Table

The loop variable is an int that steps from -40 to 100 by 10. The formula is evaluated as c * 9.0 / 5.0 + 32.0: because 9.0 is a double, the whole expression is floating-point. Writing c * (9 / 5) would compute 9 / 5 = 1 first and produce wrong results. std::fixed with std::setprecision(1) forces exactly one decimal digit.

// solution_02_temperature.cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    cout << " Celsius | Fahrenheit\n";
    cout << "---------+-----------\n";
    cout << fixed << setprecision(1);

    for (int c = -40; c <= 100; c += 10) {
        // 9.0 / 5 is floating point; plain 9 / 5 would be integer division = 1
        double f = c * 9.0 / 5.0 + 32.0;
        cout << setw(8) << c << " | " << setw(9) << f << '\n';
    }
    return 0;
}

Sanity checks: -40 maps to -40 (the temperatures where both scales agree), 0°C is 32°F and 100°C is 212°F.

Key concepts used: for loop with +=, floating-point arithmetic, integer-division avoidance, setw/fixed/setprecision.
