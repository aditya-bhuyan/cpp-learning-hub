Chapter 02 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Work through each exercise in a text editor or IDE. Compile with g++ -std=c++17 -Wall -Wextra and fix every warning. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Sizes of the Primitive Types Easy

Write a program that declares one initialized variable of each primitive type: bool, char, short, int, long, long long, float, double, long double, and unsigned int. Print a table showing each type's name, its sizeof in bytes, and the stored value.

Hint: sizeof accepts a variable name, so the size always matches the declared type. Use std::setw from <iomanip> to align the columns, and std::boolalpha to print true instead of 1.

Expected output (64-bit system):

Type            Bytes     Value
----------------------------------------
bool            1         true
char            1         C
short           2         1000
int             4         42
...
Exercise 2 — Swap Two Numbers Using XOR Easy

Read two integers and swap them without a temporary variable, using only the XOR operator (^). Print both values before and after the swap.

Hint: Three statements are enough: a ^= b; b ^= a; a ^= b;. Work through it on paper with a = 5 (0101) and b = 3 (0011) to see why it works. Think about what goes wrong if both names refer to the same variable.

Expected output (sample):

Enter two integers: 17 42
Before: a = 17, b = 42
After : a = 42, b = 17
Exercise 3 — Even or Odd with Bitwise AND Easy

Read an integer and report whether it is even or odd. Do not use % or /; use the bitwise AND operator on the lowest bit.

Hint: The lowest bit of every odd number is 1. Beware of precedence — == binds tighter than &, so write (n & 1) == 0. Test with a negative number too.

Expected output (sample):

Enter an integer: 7
7 is odd

Enter an integer: 10
10 is even
Exercise 4 — Binary Representation of an 8-Bit Number Medium

Read an integer from 0 to 255 and print its 8-bit binary representation (most significant bit first), with a space between the two nibbles. Reject values outside the range with an error message.

Do it manually with shifts and masks — do not use std::bitset (you may use it afterwards to verify your result).

Hint: Loop bit from 7 down to 0 and print (value >> bit) & 1. Store the number in an unsigned char or unsigned int so shifts behave predictably.

Expected output (sample):

Enter a number (0-255): 165
165 in binary: 1010 0101

Enter a number (0-255): 5
5 in binary: 0000 0101
Exercise 5 — Temperature Conversion Table Medium

Print a Celsius-to-Fahrenheit conversion table for every temperature from -40°C to 100°C in steps of 10. Format it as two aligned columns with one decimal place for Fahrenheit.

Formula: F = C × 9 / 5 + 32

Hint: Watch the integer-division trap — 9 / 5 is 1 in C++. Write 9.0 / 5.0 (or put the multiplication first with a floating-point operand). Use std::fixed, std::setprecision(1) and std::setw. Note that -40°C equals -40°F.

Expected output (first and last rows):

 Celsius | Fahrenheit
---------+-----------
     -40 |     -40.0
     -30 |     -22.0
     ...
     100 |     212.0
