Chapter 02 — Coding Examples

Four fully commented programs: type sizes, overflow, casting, and bit manipulation.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
How to run these examples Save each listing to a file and compile with g++ -std=c++17 -Wall -Wextra -o demo file.cpp && ./demo. Outputs shown below were produced on a 64-bit system; sizes of long and long double may differ on yours.

Example 1 — sizeof Demo — Sizes of Every Type

This program prints the size in bytes of every fundamental type, plus fixed-width integers, pointers and arrays. Run it on your own machine and compare — the numbers for long and long double differ between platforms. 

// sizeof_demo.cpp
// Compile: g++ -std=c++17 -Wall -Wextra -o sizeof_demo sizeof_demo.cpp
// Run:     ./sizeof_demo

#include <iostream>
#include <iomanip>   // std::setw
#include <climits>   // CHAR_BIT, INT_MAX, INT_MIN
#include <cstdint>   // fixed-width integer types
#include <cstddef>   // std::size_t

int main() {
    // Left-align the type names so the sizes line up in a neat column
    std::cout << std::left;

    std::cout << "=== Fundamental types (size in bytes) ===\n";
    std::cout << std::setw(24) << "bool"               << sizeof(bool)               << '\n';
    std::cout << std::setw(24) << "char"               << sizeof(char)               << '\n';
    std::cout << std::setw(24) << "short"              << sizeof(short)              << '\n';
    std::cout << std::setw(24) << "int"                << sizeof(int)                << '\n';
    std::cout << std::setw(24) << "long"               << sizeof(long)               << '\n';
    std::cout << std::setw(24) << "long long"          << sizeof(long long)          << '\n';
    std::cout << std::setw(24) << "float"              << sizeof(float)              << '\n';
    std::cout << std::setw(24) << "double"             << sizeof(double)             << '\n';
    std::cout << std::setw(24) << "long double"        << sizeof(long double)        << '\n';

    std::cout << "\n=== Unsigned variants (same size as signed) ===\n";
    std::cout << std::setw(24) << "unsigned char"      << sizeof(unsigned char)      << '\n';
    std::cout << std::setw(24) << "unsigned short"     << sizeof(unsigned short)     << '\n';
    std::cout << std::setw(24) << "unsigned int"       << sizeof(unsigned int)       << '\n';
    std::cout << std::setw(24) << "unsigned long"      << sizeof(unsigned long)      << '\n';
    std::cout << std::setw(24) << "unsigned long long" << sizeof(unsigned long long) << '\n';

    std::cout << "\n=== Fixed-width types from <cstdint> ===\n";
    std::cout << std::setw(24) << "int8_t"             << sizeof(int8_t)             << '\n';
    std::cout << std::setw(24) << "int16_t"            << sizeof(int16_t)            << '\n';
    std::cout << std::setw(24) << "int32_t"            << sizeof(int32_t)            << '\n';
    std::cout << std::setw(24) << "int64_t"            << sizeof(int64_t)            << '\n';

    std::cout << "\n=== Pointers and library types ===\n";
    std::cout << std::setw(24) << "void*"              << sizeof(void*)              << '\n';
    std::cout << std::setw(24) << "std::size_t"        << sizeof(std::size_t)        << '\n';

    // sizeof also works on variables and expressions (the operand is NOT evaluated).
    // Some compilers warn about counter++ below because it has no effect - that is the point of the demo.
    int    counter = 0;
    double values[10];
    std::cout << "\n=== sizeof on variables and arrays ===\n";
    std::cout << "sizeof(counter)        = " << sizeof(counter) << '\n';
    std::cout << "sizeof(values)         = " << sizeof(values)  << " (10 doubles)\n";
    std::cout << "elements in values     = " << sizeof(values) / sizeof(values[0]) << '\n';
    std::cout << "sizeof(counter++)      = " << sizeof(counter++)
              << " (counter is still " << counter << ")\n";

    // Bits = bytes * CHAR_BIT, and the range of a signed type follows from its width
    std::cout << "\n=== Bits and range of int ===\n";
    std::cout << "Bits in an int         = " << sizeof(int) * CHAR_BIT << '\n';
    std::cout << "INT_MIN                = " << INT_MIN << '\n';
    std::cout << "INT_MAX                = " << INT_MAX << '\n';

    return 0;
}

What to notice: unsigned types are the same size as their signed twins; sizeof(values) / sizeof(values[0]) is the idiom for an array's element count; and sizeof(counter++) does not execute the increment — sizeof only inspects the type at compile time.

Platform differences On 64-bit Windows (MSVC) sizeof(long) is 4, while on 64-bit Linux and macOS it is 8. If you need exactly 64 bits everywhere, use int64_t or long long.

Example 2 — Integer Overflow and Unsigned Wraparound

What happens when a value is too big (or too small) for its type? Unsigned integers wrap around modulo 2n. Signed overflow is undefined behaviour, so this program detects the problem rather than triggering it. It finishes with two classic traps: the signed/unsigned comparison and the never-ending unsigned countdown loop. 

// overflow_demo.cpp
// Compile: g++ -std=c++17 -Wall -Wextra -o overflow_demo overflow_demo.cpp
// Run:     ./overflow_demo
//
// Shows what happens when a value no longer fits in its type. Unsigned overflow
// is well-defined (wraps modulo 2^n). Signed overflow is UNDEFINED BEHAVIOUR, so
// this program never performs it; it detects the problem and wraps via unsigned.

#include <iostream>
#include <limits>    // std::numeric_limits
#include <climits>   // INT_MAX
#include <cstdint>   // uint8_t

int main() {
    // ---- 1. Unsigned wraparound at the top of the range ----
    unsigned int u = std::numeric_limits<unsigned int>::max();
    std::cout << "UINT_MAX            = " << u << '\n';
    u = u + 1;                                   // well-defined: wraps to 0
    std::cout << "UINT_MAX + 1        = " << u << "   (wrapped to 0)\n";

    // ---- 2. Unsigned wraparound at the bottom of the range ----
    unsigned int zero = 0;
    zero = zero - 1;                             // wraps to the largest value
    std::cout << "0u - 1              = " << zero << "   (wrapped to the maximum)\n";

    // ---- 3. An 8-bit counter wrapping around ----
    // uint8_t holds 0..255. Cast to int when printing: otherwise cout treats it as a char.
    uint8_t counter = 250;
    std::cout << "uint8_t counter     : ";
    for (int i = 0; i < 8; ++i) {
        std::cout << static_cast<int>(counter) << ' ';
        ++counter;                               // 255 + 1 wraps to 0
    }
    std::cout << '\n';

    // ---- 4. Signed overflow: detect it instead of performing it ----
    int big = INT_MAX;
    if (big > INT_MAX - 1) {
        std::cout << "INT_MAX + 1 would overflow an int - undefined behaviour, so we skip it\n";
    }

    // Do the arithmetic in unsigned and convert back to see the "two's complement" result.
    // (Implementation-defined before C++20, guaranteed modular from C++20 onwards.)
    int wrapped = static_cast<int>(static_cast<unsigned int>(big) + 1u);
    std::cout << "INT_MAX + 1 (wrapped) = " << wrapped << '\n';

    // A safer alternative: promote to a wider type before the addition
    long long safe = static_cast<long long>(big) + 1;
    std::cout << "INT_MAX + 1 (long long) = " << safe << '\n';

    // ---- 5. Signed/unsigned comparison trap ----
    int      negative = -1;
    unsigned positive = 1;
    // negative is converted to unsigned (4294967295) before comparing!
    // Compile with -Wall -Wextra to see a -Wsign-compare warning here.
    if (negative < positive) {
        std::cout << "-1 < 1u  is true\n";
    } else {
        std::cout << "-1 < 1u  is FALSE (the -1 became " << static_cast<unsigned>(negative) << ")\n";
    }

    // ---- 6. A classic loop bug with unsigned counters ----
    // for (unsigned i = 3; i >= 0; --i) never ends because i >= 0 is always true.
    // Correct pattern: test before decrementing.
    std::cout << "Counting down safely: ";
    for (unsigned i = 3; i > 0; --i) {
        std::cout << i << ' ';
    }
    std::cout << "0\n";

    return 0;
}

Output (64-bit macOS / Linux):

UINT_MAX            = 4294967295
UINT_MAX + 1        = 0   (wrapped to 0)
0u - 1              = 4294967295   (wrapped to the maximum)
uint8_t counter     : 250 251 252 253 254 255 0 1 
INT_MAX + 1 would overflow an int - undefined behaviour, so we skip it
INT_MAX + 1 (wrapped) = -2147483648
INT_MAX + 1 (long long) = 2147483648
-1 < 1u  is FALSE (the -1 became 4294967295)
Counting down safely: 3 2 1 0

What to notice: the 8-bit counter goes 255 → 0; -1 < 1u is false because -1 is converted to 4,294,967,295; and with -Wall -Wextra the compiler warns about that comparison (-Wsign-compare) — a good reason to always compile with warnings on.

Tip — detect overflow before it happens Check a > INT_MAX - b before computing a + b, widen to long long, or use __builtin_add_overflow (GCC/Clang).

Example 3 — Type Casting — Implicit Narrowing and static_cast

This program shows safe widening, lossy narrowing, the integer-division trap, and the explicit casts that document your intent. Compiling with -Wconversion makes the compiler flag each lossy implicit conversion — those warnings are deliberate here. 

// casting_demo.cpp
// Compile: g++ -std=c++17 -Wall -Wextra -Wconversion -o casting_demo casting_demo.cpp
// Run:     ./casting_demo
//
// -Wconversion makes the compiler warn about every implicit narrowing below.
// Those warnings are intentional - this program exists to show the problem.

#include <iostream>

int main() {
    // ---- 1. Implicit widening: always safe ----
    int    small = 42;
    double wide  = small;                  // int -> double, no information lost
    std::cout << "Widening  int 42 -> double: " << wide << '\n';

    char letter = 'A';
    int  code   = letter + 1;              // char is promoted to int: 65 + 1
    std::cout << "char 'A' + 1 as int      : " << code << '\n';

    // ---- 2. Implicit narrowing: compiles, but data is lost ----
    double pi = 3.99;
    int truncated = pi;                    // WARNING: fraction discarded (not rounded!)
    std::cout << "Narrowing double 3.99 -> int : " << truncated << '\n';

    double negative = -3.99;
    int negTrunc = negative;               // WARNING: truncates toward zero -> -3
    std::cout << "Narrowing double -3.99 -> int: " << negTrunc << '\n';

    int  large = 321;
    char tiny  = large;                    // WARNING: 321 does not fit in 8 bits (321 - 256 = 65)
    std::cout << "Narrowing int 321 -> char    : " << static_cast<int>(tiny)
              << " ('" << tiny << "')\n";

    // Brace initialization turns these silent bugs into compile errors:
    // int safeInit{pi};                   // error: narrowing conversion of 'pi' from 'double' to 'int'

    // ---- 3. The integer division trap ----
    int sum = 17, count = 4;
    double wrongAvg = sum / count;                         // integer division FIRST -> 4, then 4.0
    double rightAvg = static_cast<double>(sum) / count;    // 17.0 / 4 -> 4.25
    std::cout << "\nsum / count (wrong)          : " << wrongAvg << '\n';
    std::cout << "static_cast<double>(sum)/count: " << rightAvg << '\n';

    // The cast applies to sum ALONE, before the division. This is NOT the same thing:
    double alsoWrong = static_cast<double>(sum / count);   // division still done in ints
    std::cout << "static_cast<double>(sum/count): " << alsoWrong << '\n';

    // ---- 4. static_cast for explicit, intentional conversions ----
    double price = 19.99;
    int    dollars = static_cast<int>(price);              // intent is clear: drop the cents
    int    rounded = static_cast<int>(price + 0.5);        // simple rounding for positive values
    std::cout << "\nprice " << price << " -> dollars " << dollars
              << ", rounded " << rounded << '\n';

    char next = static_cast<char>('a' + 1);                // int result converted back to char
    std::cout << "'a' + 1 as char           : " << next << '\n';

    int ascii = static_cast<int>('Z');                     // see the numeric code of a char
    std::cout << "numeric code of 'Z'       : " << ascii << '\n';

    // ---- 5. C-style and functional casts (work, but avoid them) ----
    int cStyle = (int)pi;                                  // C-style: can hide dangerous conversions
    int funcStyle = int(pi);                               // functional style
    std::cout << "\nC-style cast  (int)3.99 : " << cStyle << '\n';
    std::cout << "functional cast int(3.99): " << funcStyle << '\n';

    // ---- 6. Mixed arithmetic: usual arithmetic conversions ----
    int    apples = 7;
    double weight = 0.5;
    auto   total  = apples * weight;                       // int is converted to double
    std::cout << "7 * 0.5 -> " << total << " (type double)\n";

    return 0;
}

Output (64-bit macOS / Linux):

Widening  int 42 -> double: 42
char 'A' + 1 as int      : 66
Narrowing double 3.99 -> int : 3
Narrowing double -3.99 -> int: -3
Narrowing int 321 -> char    : 65 ('A')

sum / count (wrong)          : 4
static_cast<double>(sum)/count: 4.25
static_cast<double>(sum/count): 4

price 19.99 -> dollars 19, rounded 20
'a' + 1 as char           : b
numeric code of 'Z'       : 90

C-style cast  (int)3.99 : 3
functional cast int(3.99): 3
7 * 0.5 -> 3.5 (type double)

What to notice: narrowing 3.99 gives 3 (truncation, not rounding); 321 in a char becomes 65 ('A') because only the low 8 bits survive; and static_cast<double>(sum / count) is still wrong because the division happens before the cast.

Place the cast on an operand, not on the result static_cast<double>(a) / b converts a first, so the division is floating-point. static_cast<double>(a / b) converts a result that has already lost its fraction.

Example 4 — Bitwise Operations — Odd Check, Set, Clear, Toggle

Small helper functions wrap the standard bit-twiddling idioms: test the lowest bit to find odd numbers, then use |, & ~, and ^ with a mask 1u << pos to set, clear, and toggle a chosen bit. std::bitset<8> prints each value in binary so you can see exactly what changed. 

// bitwise_demo.cpp
// Compile: g++ -std=c++17 -Wall -Wextra -o bitwise_demo bitwise_demo.cpp
// Run:     ./bitwise_demo
//
// Bit positions are numbered from 0 at the RIGHT (least significant bit):
//     bit:  7 6 5 4 3 2 1 0
//     n=45: 0 0 1 0 1 1 0 1

#include <iostream>
#include <iomanip>   // std::setw
#include <bitset>    // std::bitset - prints a number in binary

// Prints a label, the value in 8-bit binary, and in decimal
void show(const char* label, unsigned int value) {
    std::cout << std::left << std::setw(26) << label
              << std::bitset<8>(value) << "  (" << value << ")\n";
}

// An integer is odd exactly when its lowest bit is 1
bool isOdd(int n) {
    return (n & 1) != 0;
}

// Return a copy of value with bit 'pos' forced to 1:   OR with a mask
unsigned int setBit(unsigned int value, int pos) {
    return value | (1u << pos);
}

// Return a copy of value with bit 'pos' forced to 0:   AND with an inverted mask
unsigned int clearBit(unsigned int value, int pos) {
    return value & ~(1u << pos);
}

// Return a copy of value with bit 'pos' flipped:       XOR with a mask
unsigned int toggleBit(unsigned int value, int pos) {
    return value ^ (1u << pos);
}

// Is bit 'pos' set?
bool testBit(unsigned int value, int pos) {
    return ((value >> pos) & 1u) != 0;
}

int main() {
    // ---- Part 1: odd / even with n & 1 ----
    std::cout << "--- Odd or even? ---\n";
    int samples[] = {7, 10, 0, -3};
    for (int n : samples) {
        std::cout << std::setw(3) << n << " is " << (isOdd(n) ? "odd" : "even") << '\n';
    }

    // ---- Part 2: set / clear / toggle / test a bit ----
    std::cout << "\n--- Bit manipulation ---\n";
    unsigned int value = 45;                       // 00101101
    show("original", value);

    value = setBit(value, 1);                      // 00101101 | 00000010 = 00101111
    show("setBit(1)", value);

    value = clearBit(value, 0);                    // 00101111 & 11111110 = 00101110
    show("clearBit(0)", value);

    value = toggleBit(value, 5);                   // bit 5 was 1 -> becomes 0
    show("toggleBit(5)", value);

    value = toggleBit(value, 5);                   // toggling again restores it
    show("toggleBit(5) again", value);

    std::cout << "testBit(3) = " << std::boolalpha << testBit(value, 3) << '\n';
    std::cout << "testBit(4) = " << testBit(value, 4) << '\n';

    // ---- Part 3: the six bitwise operators on 12 (1100) and 10 (1010) ----
    std::cout << "\n--- Operators on a=12, b=10 ---\n";
    unsigned int a = 12, b = 10;
    show("a",       a);
    show("b",       b);
    show("a & b",   a & b);
    show("a | b",   a | b);
    show("a ^ b",   a ^ b);
    show("~a (8 bits)", ~a & 0xFFu);               // mask to keep just the low 8 bits
    show("a << 2",  a << 2);
    show("a >> 2",  a >> 2);

    return 0;
}

Output (64-bit macOS / Linux):

--- Odd or even? ---
  7 is odd
 10 is even
  0 is even
 -3 is odd

--- Bit manipulation ---
original                  00101101  (45)
setBit(1)                 00101111  (47)
clearBit(0)               00101110  (46)
toggleBit(5)              00001110  (14)
toggleBit(5) again        00101110  (46)
testBit(3) = true
testBit(4) = false

--- Operators on a=12, b=10 ---
a                         00001100  (12)
b                         00001010  (10)
a & b                     00001000  (8)
a | b                     00001110  (14)
a ^ b                     00000110  (6)
~a (8 bits)               11110011  (243)
a << 2                    00110000  (48)
a >> 2                    00000011  (3)

What to notice: -3 & 1 is 1 on two's-complement machines, so negative odd numbers are detected correctly (whereas n % 2 == 1 would fail for -3 because -3 % 2 is -1). Toggling the same bit twice restores the original value.

The mask pattern Every single-bit operation builds a mask 1u << pos (a 1 in the target position, zeros elsewhere), then combines it with the value: | to force on, & ~mask to force off, ^ to flip, & to test.

Key Observations

  • sizeof is a compile-time operator; it never evaluates its operand.
  • Unsigned arithmetic wraps; signed overflow is undefined — never rely on it.
  • Implicit narrowing compiles silently; enable -Wconversion or use {} initialization to catch it.
  • Masks built with 1u << pos give you set, clear, toggle, and test in one line each.
