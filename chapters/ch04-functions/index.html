Chapter 04 — Functions

Build reusable, modular code: declarations, definitions, parameters, overloading, recursion, and scope.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz

4.1 Why Functions?

A function is a named, self-contained block of code that performs a specific task. Well-designed functions are the backbone of maintainable software. They deliver three fundamental engineering benefits:

  • Code reuse — Write logic once, invoke it anywhere. If the logic changes, you update it in one place. Without functions you would copy-paste the same loop or formula across your program and risk introducing subtle inconsistencies.
  • Modularity — Large programs are decomposed into small, independently testable units. Each function has a clear contract: given these inputs, produce this output. The caller does not need to know how it works, only what it does.
  • Abstraction — Functions hide complexity behind a simple name. Calling sqrt(x) is far clearer than embedding the Newton–Raphson iteration inline. Good naming makes code read almost like prose.

4.2 Declaration, Definition, and Call

A function has three distinct syntactic roles you must understand separately:

RoleWhat it providesAlso called
DeclarationReturn type, name, and parameter types — the function's signature. No body.Prototype, forward declaration
DefinitionEverything in the declaration plus the function body (the { } block).Implementation
CallAn expression that invokes the function and passes arguments.Invocation
 
// ── Declaration (prototype) ──────────────────────────────
// Tells the compiler: "a function named add exists, it takes two ints, returns int"
int add(int a, int b);   // semicolon — no body

// ── Definition ───────────────────────────────────────────
// Provides the body.  May serve double-duty as the declaration if placed before any call.
int add(int a, int b) {
    return a + b;        // function body
}

// ── Call ─────────────────────────────────────────────────
int result = add(3, 7);  // result == 10
Why forward-declare? If you define funcA after funcB, but funcB calls funcA, the compiler has not yet seen funcA when it processes funcB. A declaration placed at the top of the file (or in a header) resolves this ordering problem.

4.3 Return Types

The return type is written before the function name and specifies what type of value the function produces. A function that produces no value uses void.

Return typeMeaningExample
voidNo return valuevoid printBanner();
intWhole numberint countWords(string s);
doubleFloating-point numberdouble circleArea(double r);
booltrue / falsebool isPrime(int n);
stringTextstring toUpperCase(string s);

#include <iostream>
#include <string>
using namespace std;

void    greet(string name)  { cout << "Hello, " << name << "!\n"; }
int     square(int x)       { return x * x; }
double  half(double x)      { return x / 2.0; }
bool    isEven(int x)       { return (x % 2 == 0); }

int main() {
    greet("Alice");                    // Hello, Alice!
    cout << square(7) << "\n";        // 49
    cout << half(9.0) << "\n";        // 4.5
    cout << isEven(4) << "\n";        // 1  (true)
}

4.4 Parameters: Pass by Value, Reference, and Const Reference

4.4.1 Pass by Value (Copy)

The default parameter-passing mode. The function receives a copy of the argument; the original variable is unchanged no matter what the function does. 

void doubleIt(int x) {
    x *= 2;           // modifies the local COPY of x
}

int main() {
    int n = 5;
    doubleIt(n);
    cout << n << "\n"; // still 5 — original untouched
}

4.4.2 Pass by Reference (&)

The parameter is an alias for the caller's variable. Changes inside the function are visible to the caller. Use this when you intentionally want to modify the argument (e.g., a swap function) or when passing a large object to avoid the cost of copying. 

void doubleIt(int& x) {   // & makes x an alias
    x *= 2;               // modifies the ORIGINAL variable
}

int main() {
    int n = 5;
    doubleIt(n);
    cout << n << "\n"; // 10
}

4.4.3 Pass by Const Reference

Combines efficiency (no copy) with safety (cannot be modified). The idiomatic way to pass large objects like string, vector, or custom classes when the function only needs to read them. 

// Efficient and safe — no copy of the (potentially large) string is made
void printLength(const string& s) {
    // s = "modified";  ← compile error: s is read-only
    cout << "Length: " << s.size() << "\n";
}

int main() {
    string city = "San Francisco";
    printLength(city); // Length: 13
}
Rule of thumb: Pass built-in types (int, double, bool, char) by value. Pass objects and containers either by const& (read-only) or by & (if you need to modify them).

4.5 Default Parameter Values

Parameters can have default values, making them optional at the call site. Default values must appear on the rightmost parameters — you cannot have a default parameter followed by a non-default one. 

// Default parameters must be on the RIGHT
void greet(string name, string prefix = "Hello") {
    cout << prefix << ", " << name << "!\n";
}

int main() {
    greet("Alice");           // Hello, Alice!      (prefix uses default)
    greet("Bob", "Hey");      // Hey, Bob!           (prefix overridden)
    greet("Carol", "Hi");     // Hi, Carol!
}
Default values in declarations vs definitions Put default values in the declaration (or the first time the compiler sees the function). Do not repeat them in the definition — that is a compile error.

4.6 Function Overloading

C++ allows multiple functions to share the same name as long as their parameter lists differ (different number of parameters, different types, or both). The compiler selects the correct version based on the argument types at the call site — this is called overload resolution. 

#include <iostream>
#include <cmath>     // M_PI
using namespace std;

const double PI = 3.14159265358979;

// Three overloads of area()
double area(double radius) {                         // circle
    return PI * radius * radius;
}
double area(double width, double height) {           // rectangle
    return width * height;
}
double area(double base, double height, bool) {      // triangle
    return 0.5 * base * height;
}

int main() {
    cout << area(5.0)          << "\n";  // 78.5398 (circle)
    cout << area(4.0, 6.0)     << "\n";  // 24       (rectangle)
    cout << area(3.0, 8.0, true) << "\n"; // 12       (triangle)
}
Note: The return type alone is not enough to distinguish overloads. Two functions with identical parameter lists but different return types will produce a compile error.

4.7 Recursion

A recursive function calls itself. Every recursive solution requires:

  1. Base case — A condition under which the function returns a result directly, without recursing. This stops the chain of calls.
  2. Recursive case — The function calls itself with a simpler or smaller version of the problem, progressing toward the base case.
// Recursive factorial: n! = n × (n-1)!
// Base case: 0! = 1
long long factorial(int n) {
    if (n <= 0) return 1;       // base case
    return n * factorial(n - 1); // recursive case
}

int main() {
    cout << factorial(5) << "\n"; // 120
    cout << factorial(10) << "\n"; // 3628800
}

Call-stack visualisation for factorial(4):

factorial(4)
  └─ 4 * factorial(3)
           └─ 3 * factorial(2)
                    └─ 2 * factorial(1)
                             └─ 1 * factorial(0)
                                      └─ returns 1    ← base case
                             returns 1 * 1 = 1
                    returns 2 * 1 = 2
           returns 3 * 2 = 6
  returns 4 * 6 = 24
Stack Overflow from Infinite Recursion Every function call consumes stack memory. A recursive function with no base case — or a base case that is never reached — will keep calling itself until the program's call stack is exhausted. The OS then terminates the program with a stack overflow (segmentation fault on Linux, stack overflow exception on Windows). Always verify your base case is reachable from all possible inputs.

4.8 Scope: Local vs Global Variables

Scope determines where a variable is visible and accessible.

  • Local variable — Declared inside a function or block. Exists only while that block executes. Created on the stack when the block is entered; destroyed when the block exits.
  • Global variable — Declared outside all functions, at file scope. Exists for the entire lifetime of the program. Accessible from any function in the same translation unit.
#include <iostream>
using namespace std;

int globalCount = 0;   // global — lives for the entire program

void increment() {
    int localStep = 1; // local — recreated on every call
    globalCount += localStep;
    cout << "localStep address: " << &localStep << "\n"; // changes each call
}

int main() {
    increment(); // globalCount == 1
    increment(); // globalCount == 2
    cout << globalCount << "\n"; // 2
}

Variable Shadowing

When a local variable shares its name with a global (or an outer-scope variable), the local one shadows the outer one inside that block. 

#include <iostream>
using namespace std;

int x = 100;   // global x

void show() {
    int x = 42; // local x — shadows the global x inside show()
    cout << x << "\n";   // 42 (local)
    cout << ::x << "\n"; // 100 (global, accessed via scope-resolution operator)
}

int main() {
    show();
    cout << x << "\n"; // 100 (global, local x no longer exists)
}

4.9 Inline Functions

The inline keyword is a hint to the compiler to replace each call to the function with the function's body directly at the call site, avoiding the overhead of a function call (stack frame setup, jump, return). Modern compilers often inline small functions automatically regardless of the keyword, and may ignore inline for large functions. 

inline int max(int a, int b) {
    return (a > b) ? a : b;
}

int main() {
    // The compiler may expand this to: int m = (3 > 7) ? 3 : 7;
    int m = max(3, 7);
    cout << m << "\n"; // 7
}
When to use inline? Short, frequently-called utility functions (e.g., min, max, simple getters in a class). Do not mark large or recursive functions as inline.

4.10 Functions as Arguments — Function Pointers

In C++, a function's address can be stored in a function pointer and passed to another function. This enables callbacks and higher-order programming patterns. The syntax is verbose but important as a foundation for understanding C++ lambdas and std::function (covered in Chapter 15). 

#include <iostream>
using namespace std;

// A simple comparator function
bool ascending(int a, int b)  { return a < b; }
bool descending(int a, int b) { return a > b; }

// Takes a function pointer as the third parameter
void printOrdered(int x, int y, bool (*cmp)(int, int)) {
    if (cmp(x, y))
        cout << x << " comes before " << y << "\n";
    else
        cout << y << " comes before " << x << "\n";
}

int main() {
    printOrdered(3, 9, ascending);  // 3 comes before 9
    printOrdered(3, 9, descending); // 9 comes before 3
}

4.11 Key Takeaways

  • Functions promote reuse, modularity, and abstraction.
  • A declaration gives the compiler the signature; a definition gives the body.
  • Pass by value copies the argument; pass by reference aliases it; pass by const reference aliases it read-only.
  • Default parameters must be on the rightmost side of the parameter list.
  • Function overloading allows same-named functions with different parameter lists.
  • Recursive functions need a base case; without one they cause a stack overflow.
  • Local variables live in the function's stack frame; global variables live for the program's lifetime.
  • The inline keyword is a compiler hint to avoid call overhead for small functions.
  • Function pointers let you pass behaviour as an argument.
