Chapter 04 — Solutions

Reference solutions with explanations. Only read after attempting the exercises yourself.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Spoiler Warning These are reference solutions. There are often multiple valid approaches — if your output matches but your code differs, that is perfectly fine.
✅ Solution 1 — isPrime

The key optimisation is testing divisors only up to sqrt(n). If n has a factor larger than its square root, it must also have a corresponding factor smaller than its square root — so we would have already found it. 

// solution_04_isprime.cpp
// Compile: g++ -std=c++17 -Wall -o solution_04_isprime solution_04_isprime.cpp

#include <iostream>
#include <cmath>    // sqrt
using namespace std;

// Returns true if n is prime, false otherwise.
bool isPrime(int n) {
    if (n < 2)  return false;   // 0, 1, negatives: not prime
    if (n == 2) return true;    // 2 is the only even prime
    if (n % 2 == 0) return false; // all other evens are not prime

    // Check odd divisors from 3 up to sqrt(n)
    int limit = static_cast<int>(sqrt(static_cast<double>(n)));
    for (int i = 3; i <= limit; i += 2) {
        if (n % i == 0) return false;
    }
    return true;
}

int main() {
    cout << "Primes up to 50: ";
    for (int i = 1; i <= 50; ++i) {
        if (isPrime(i)) cout << i << " ";
    }
    cout << "\n";
    return 0;
}

Key concepts used: early-return guard clauses, sqrt, loop stepping by 2 to skip evens.

✅ Solution 2 — Overloaded power()

Both overloads implement a simple repeated-multiplication loop. The compiler selects the int version when both arguments are integers, and the double version when the base is a floating-point literal. 

// solution_04_power.cpp
// Compile: g++ -std=c++17 -Wall -o solution_04_power solution_04_power.cpp

#include <iostream>
#include <iomanip>
using namespace std;

// Overload 1: integer base and exponent
int power(int base, int exponent) {
    int result = 1;
    for (int i = 0; i < exponent; ++i)
        result *= base;
    return result;
}

// Overload 2: double base, integer exponent
double power(double base, int exponent) {
    double result = 1.0;
    for (int i = 0; i < exponent; ++i)
        result *= base;
    return result;
}

int main() {
    cout << fixed << setprecision(4);
    cout << "power(2, 10)    = " << power(2, 10)    << "\n";   // int overload
    cout << "power(3, 5)     = " << power(3, 5)     << "\n";   // int overload
    cout << "power(2.5, 3)   = " << power(2.5, 3)   << "\n";   // double overload
    cout << "power(1.5, 4)   = " << power(1.5, 4)   << "\n";   // double overload
    cout << "power(5, 0)     = " << power(5, 0)     << "\n";   // any number^0 = 1
    return 0;
}

Key concepts used: function overloading, loop-based exponentiation, type deduction at call site.

✅ Solution 3 — Recursive GCD (Euclidean Algorithm)

The Euclidean algorithm is a classic example of elegant recursion. At each step it replaces the larger number with a % b, which decreases in size monotonically, guaranteeing termination. The base case b == 0 is always reached. 

// solution_04_gcd.cpp
// Compile: g++ -std=c++17 -Wall -o solution_04_gcd solution_04_gcd.cpp

#include <iostream>
using namespace std;

// Recursive GCD with step tracing
int gcd(int a, int b) {
    cout << "  gcd(" << a << ", " << b << ")\n";
    if (b == 0) return a;       // base case
    return gcd(b, a % b);       // recursive case: Euclidean reduction
}

int main() {
    int a, b;
    cout << "Enter two integers: ";
    cin >> a >> b;

    // Ensure positive inputs for simplicity
    if (a < 0) a = -a;
    if (b < 0) b = -b;

    int result = gcd(a, b);
    cout << "GCD = " << result << "\n";
    return 0;
}

Key concepts used: recursion, modulo operator, base case termination proof.

✅ Solution 4 — Palindrome Checker

The two-pointer technique compares characters from opposite ends, advancing inward. Case is normalised with tolower so "Madam" and "madam" are both recognised as palindromes. Passing by const string& avoids an unnecessary copy of the string. 

// solution_04_palindrome.cpp
// Compile: g++ -std=c++17 -Wall -o solution_04_palindrome solution_04_palindrome.cpp

#include <iostream>
#include <string>
#include <cctype>   // tolower
using namespace std;

// Returns true if s is a palindrome (case-insensitive).
// const string& — no copy; the function cannot modify the original.
bool isPalindrome(const string& s) {
    int left  = 0;
    int right = static_cast<int>(s.size()) - 1;

    while (left < right) {
        // Compare characters after normalising case
        if (tolower(s[left]) != tolower(s[right]))
            return false;
        ++left;
        --right;
    }
    return true;  // all pairs matched
}

int main() {
    // Test cases
    string words[] = {"racecar", "Madam", "hello", "Level", "OpenAI"};
    for (const string& w : words) {
        cout << "\"" << w << "\""
             << (isPalindrome(w) ? " -> palindrome" : " -> not a palindrome")
             << "\n";
    }
    return 0;
}

Key concepts used: const string& parameter, two-pointer technique, tolower, range-based for loop.

✅ Solution 5 — Recursive String Permutations

The algorithm fixes each character in the leftmost unfixed position in turn (by swapping it there), then recurses on the remaining suffix. After the recursive call it swaps back (backtracking) to restore the string for the next iteration. For a string of length n this generates exactly n! permutations. 

// solution_04_permute.cpp
// Compile: g++ -std=c++17 -Wall -o solution_04_permute solution_04_permute.cpp

#include <iostream>
#include <string>
using namespace std;

// Generates all permutations of s[left..right] by backtracking.
// s     — working copy of the string (passed by value for independence)
// left  — the index we are currently filling
// right — the last index (= s.size() - 1)
// count — reference counter so we can report the total
void permute(string s, int left, int right, int& count) {
    if (left == right) {          // base case: one complete permutation
        cout << s << "\n";
        ++count;
        return;
    }
    // Try placing each character s[i] at position left
    for (int i = left; i <= right; ++i) {
        swap(s[left], s[i]);               // place s[i] at position left
        permute(s, left + 1, right, count); // recurse on the rest
        swap(s[left], s[i]);               // backtrack: restore original order
    }
}

int main() {
    string word = "ABC";
    int count = 0;

    cout << "All permutations of \"" << word << "\":\n";
    permute(word, 0, static_cast<int>(word.size()) - 1, count);
    cout << "\nTotal: " << count << " permutations\n";

    return 0;
}

Key concepts used: recursion, backtracking, std::swap, pass-by-value string for independent branches, pass-by-reference counter.

Why pass s by value? Each recursive branch needs its own independent copy of the string so that swaps in one branch do not affect siblings. Passing by value gives each call its own copy automatically. The backtrack swap after the recursive call is a belt-and-suspenders redundancy here, but it is the canonical pattern you will see in most textbooks.
