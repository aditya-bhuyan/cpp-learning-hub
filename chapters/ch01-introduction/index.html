Chapter 01 — Introduction to C++

From the origins of C++ to writing, compiling, and running your first program.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz

1.1 What is C++?

C++ is a general-purpose, statically typed, compiled programming language created by Bjarne Stroustrup at Bell Labs in 1979. Originally called "C with Classes", it was renamed C++ in 1983 (the ++ operator being a nod to incrementing — i.e., an improvement over C).

C++ sits at an unusual position in the language ecosystem: it provides low-level memory control (like C) while also supporting high-level abstractions such as classes, templates, and the Standard Template Library (STL). This dual nature makes it the language of choice for operating systems, game engines, embedded firmware, real-time trading systems, and high-performance applications.

1.3 Why Learn C++?

  • Performance: Compiled to native machine code — no runtime overhead from a virtual machine or interpreter.
  • Control: Manual memory management gives fine-grained control over resources (essential in embedded and systems programming).
  • Ubiquity: Powers browsers (Chrome V8), game engines (Unreal Engine), databases (MySQL), and the Linux kernel.
  • Career value: Consistently ranks among the top 5 most demanded programming languages.
  • Teaches fundamentals: Understanding pointers, stack vs heap, and compilation makes you a better programmer in any language.

1.4 The C++ Build Process

Unlike interpreted languages (Python, JavaScript), C++ source code must be compiled before it runs. The process has four stages:

  1. Preprocessing — The preprocessor handles #include, #define, and other directives, producing a single translation unit.
  2. Compilation — The compiler (e.g., g++, clang++, MSVC) translates each translation unit into assembly code and then object code (.o / .obj).
  3. Linking — The linker combines all object files and resolves references to library symbols, producing a final executable.
  4. Loading & Execution — The OS loads the executable into memory and transfers control to main().
Compilation command (GCC/Clang) g++ -std=c++17 -Wall -o hello hello.cpp
-std=c++17 sets the language standard  |  -Wall enables all warnings  |  -o hello names the output executable

1.5 Program Structure — Anatomy of a C++ Program

Every C++ program must have exactly one main() function — this is the entry point where execution begins.

// Preprocessor directive — includes the I/O stream library
#include <iostream>

// The std namespace contains cout, cin, endl, etc.
using namespace std;

// main() returns an int (0 = success, non-zero = error)
int main() {
    // cout is the standard output stream; << is the stream insertion operator
    cout << "Hello, World!" << endl;

    return 0;   // Signal successful program termination
}

1.6 Input and Output Streams

C++ uses a stream-based I/O model defined in the <iostream> header. Streams abstract away the underlying device (console, file, network socket) behind a uniform interface.

ObjectPurposeDirection
std::coutStandard output (console)Output (write)
std::cinStandard input (keyboard)Input (read)
std::cerrStandard error (unbuffered)Output (write)
std::clogStandard log (buffered)Output (write)
 
#include <iostream>
#include <string>
using namespace std;

int main() {
    string name;
    int age;

    cout << "Enter your name: ";
    cin  >> name;          // >> is the stream extraction operator

    cout << "Enter your age: ";
    cin  >> age;

    cout << "Hello, " << name << "! You are " << age << " years old.\n";
    return 0;
}
Tip — std::endl vs \n endl flushes the output buffer in addition to inserting a newline. For performance-sensitive output (e.g., writing millions of lines), prefer '\n'. Use endl only when you explicitly need a flush (e.g., before reading user input or writing to a log).

1.7 Comments

Comments are ignored by the compiler. They document intent and improve readability.

// Single-line comment — everything after // is ignored

/* Multi-line comment —
   useful for longer explanations
   or temporarily disabling code */

/**
 * Doxygen-style comment — used to auto-generate documentation
 * @param x  the input value
 * @return   the square of x
 */
int square(int x) { return x * x; }

1.8 Setting Up Your Development Environment

Option A — GCC on Linux / macOS

  • Linux: sudo apt install g++ build-essential
  • macOS: xcode-select --install (installs Clang + g++ alias)
  • Compile: g++ -std=c++17 -Wall -o program program.cpp && ./program

Option B — MSVC on Windows

  • Install Visual Studio Community (free) and select the "Desktop development with C++" workload.
  • Or install MinGW-w64 for GCC on Windows.

Option C — Online Compilers (zero setup)

  • Compiler Explorer (godbolt.org) — shows assembly output
  • Wandbox — multiple compiler versions
  • Replit — full online IDE

1.9 Key Takeaways

  • C++ is a compiled, statically typed, multi-paradigm language.
  • The build pipeline: Preprocessing → Compilation → Linking → Execution.
  • Every program begins at int main().
  • cout writes to the console; cin reads from the keyboard.
  • Use -std=c++17 (or later) when compiling to access modern features.
