Chapter 01 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Work through each exercise in a text editor or IDE. Compile and run your program. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Personal Greeting Program Easy

Write a C++ program that:

  1. Asks the user to enter their full name (first and last, separated by a space).
  2. Asks the user to enter their favourite programming language.
  3. Prints: Hello, [Full Name]! Great choice learning [Language].

Hint: To read a full name with spaces, use std::getline(cin, name) instead of cin >> name.

Expected output (sample):

Enter your full name: Jane Doe
Enter your favourite language: C++
Hello, Jane Doe! Great choice learning C++.
Exercise 2 — Circle Area Calculator Easy

Write a program that reads the radius of a circle (as a double) and outputs:

  • The area (π × r²)
  • The circumference (2 × π × r)

Use the constant const double PI = 3.14159265358979;. Output values rounded to 4 decimal places using std::fixed and std::setprecision(4) from <iomanip>.

Expected output (sample):

Enter radius: 7.5
Area         = 176.7146 cm²
Circumference = 47.1239 cm
Exercise 3 — Simple Interest Calculator Easy

Write a program that computes Simple Interest given:

  • Principal amount P (double)
  • Annual interest rate R as a percentage (double)
  • Time period T in years (int)

Formula: SI = (P × R × T) / 100

Print the simple interest and the total amount (P + SI).

Expected output (sample):

Principal  : 10000
Rate (%)   : 5.5
Time (yrs) : 3
---
Simple Interest : 1650.00
Total Amount    : 11650.00
Exercise 4 — Unit Converter (Kilometres to Miles) Medium

Write a program that converts distances between kilometres and miles.

  • 1 kilometre = 0.621371 miles
  • Ask the user whether they want to convert km → miles or miles → km.
  • Read their choice (e.g., 1 for km→miles, 2 for miles→km).
  • Read the distance value and print the converted result.

Expected output (sample):

Distance Converter
------------------
1. Kilometres to Miles
2. Miles to Kilometres
Choice: 1
Enter distance in km: 42.195
42.195 km = 26.219 miles
Exercise 5 — BMI Calculator Medium

Write a program that calculates a person's Body Mass Index (BMI):

Formula: BMI = weight (kg) / (height (m))²

Print the BMI value and a category:

  • BMI < 18.5 → Underweight
  • 18.5 ≤ BMI < 25.0 → Normal weight
  • 25.0 ≤ BMI < 30.0 → Overweight
  • BMI ≥ 30.0 → Obese

Note: You'll need an if/else statement — a preview of Chapter 3. Look it up or take a guess!

Expected output (sample):

Enter weight (kg): 70
Enter height (m) : 1.75
BMI = 22.86 — Normal weight
