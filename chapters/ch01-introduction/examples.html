Chapter 01 — Coding Examples

Four fully explained programs covering the fundamentals of C++ I/O and structure.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz

Example 1 — Hello, World!

The classic first program. Every C++ programmer writes it. It confirms your toolchain is working and demonstrates the minimum structure of a valid C++ program. 

// hello.cpp
// Compile: g++ -std=c++17 -o hello hello.cpp
// Run:     ./hello

#include <iostream>   // provides std::cout, std::endl

int main() {
    // std::cout is the standard output stream
    // << is the stream-insertion operator — it "inserts" data into the stream
    std::cout << "Hello, World!" << std::endl;

    // Returning 0 tells the operating system the program ran successfully
    return 0;
}

Expected output:

Hello, World!
Why std::? cout and endl live inside the std namespace. You can avoid typing std:: everywhere by adding using namespace std; after your includes — but be aware this can cause name collisions in larger projects.

Example 2 — Reading User Input

This example demonstrates reading a name and an integer age from the keyboard using std::cin, then printing a personalised greeting. 

// greeting.cpp
#include <iostream>
#include <string>    // std::string
using namespace std;

int main() {
    string name;
    int    age;

    cout << "Enter your first name: ";
    cin  >> name;     // reads one whitespace-delimited token

    cout << "Enter your age: ";
    cin  >> age;

    cout << "\nNice to meet you, " << name << "!\n";
    cout << "In 10 years you will be " << (age + 10) << " years old.\n";

    return 0;
}

Sample session:

Enter your first name: Alice
Enter your age: 28

Nice to meet you, Alice!
In 10 years you will be 38 years old.

Example 3 — Area and Perimeter Calculator

A practical first program: reads the width and height of a rectangle, then computes both its area and perimeter. Introduces arithmetic expressions and double type. 

// rectangle.cpp
#include <iostream>
using namespace std;

int main() {
    double width, height;

    cout << "Rectangle Calculator\n";
    cout << "--------------------\n";
    cout << "Enter width  (metres): ";
    cin  >> width;
    cout << "Enter height (metres): ";
    cin  >> height;

    double area      = width * height;
    double perimeter = 2.0 * (width + height);

    cout << "\nResults:\n";
    cout << "  Area      = " << area      << " m²\n";
    cout << "  Perimeter = " << perimeter << " m\n";

    return 0;
}

Sample session:

Rectangle Calculator
--------------------
Enter width  (metres): 5.5
Enter height (metres): 3.2

Results:
  Area      = 17.6 m²
  Perimeter = 17.4 m

Example 4 — Temperature Converter

Converts a Celsius temperature to Fahrenheit and Kelvin. Demonstrates the use of named constants with const and formatted arithmetic output. 

// temperature.cpp
#include <iostream>
using namespace std;

int main() {
    // Named constants make the formula self-documenting
    const double ABSOLUTE_ZERO_OFFSET = 273.15;
    const double FAHRENHEIT_SCALE     = 9.0 / 5.0;
    const double FAHRENHEIT_OFFSET    = 32.0;

    double celsius;
    cout << "Enter temperature in Celsius: ";
    cin  >> celsius;

    double fahrenheit = celsius * FAHRENHEIT_SCALE + FAHRENHEIT_OFFSET;
    double kelvin     = celsius + ABSOLUTE_ZERO_OFFSET;

    cout << "\n" << celsius << " °C  =  "
         << fahrenheit << " °F  =  "
         << kelvin     << " K\n";

    return 0;
}

Sample session:

Enter temperature in Celsius: 100

100 °C  =  212 °F  =  373.15 K
