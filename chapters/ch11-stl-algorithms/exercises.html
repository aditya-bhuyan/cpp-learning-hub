Chapter 11 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Write each program in a text editor or IDE, compile with g++ -std=c++17 -Wall, and test it. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Sort and Binary Search Easy

Given vector<int> v = {42, 7, 19, 3, 88, 25, 61};, use std::sort to sort it ascending and print it. Then use std::binary_search to report whether 25 and 50 are present.

Hint: binary_search only gives correct answers on a sorted range — sort first.

Expected output:

Sorted: 3 7 19 25 42 61 88
25 found
50 not found
Exercise 2 — Count the Primes Easy

Write a function bool isPrime(int n). Then use std::count_if to count how many numbers in {1, 2, 3, ..., 15} are prime, and print the count and the primes themselves.

Hint: 0 and 1 are not prime. You only need to test divisors up to sqrt(n) (i.e. while d * d <= n). A plain function name can be passed straight to count_if.

Expected output:

Primes in the vector: 6
They are: 2 3 5 7 11 13
Exercise 3 — Square with transform Medium

Given vector<int> nums = {1, 2, 3, 4, 5, 6};, use std::transform to build a new vector containing the square of each element. The original vector must remain unchanged. Print both.

Hint: Use std::back_inserter for the output iterator (include <iterator>), or pre-size the destination vector.

Expected output:

Original: 1 2 3 4 5 6
Squares : 1 4 9 16 25 36
Exercise 4 — Find Duplicates Medium

Given vector<int> v = {4, 1, 7, 4, 9, 1, 4, 2, 7};, find every value that appears more than once. Use std::sort followed by std::adjacent_find. Each duplicated value must be reported only once, even if it appears three times.

Hint: After sorting, equal values sit side by side. adjacent_find returns the first position where two neighbours are equal; to avoid reporting the same value again, skip past the whole run (for example with std::find_if) before searching again.

Expected output:

Duplicated values: 1 4 7
Exercise 5 — Student Report Hard

Define struct Student { std::string name; int grade; }; and create this vector: 

Alice 92, Bob 58, Carol 75, Dave 49, Eve 88, Frank 60, Grace 95

Using sort, partition and transform, produce a report such that:

  1. Students with grade >= 60 (PASS) come first, followed by those who fail (use stable_partition).
  2. Within each group, students are sorted by grade descending (sort each half separately using the iterator returned by the partition).
  3. transform each student into a formatted line name grade PASS/FAIL stored in a vector<string>, then print the lines and the number of passes and fails.

Hint: The iterator returned by stable_partition marks the boundary — use sort(begin, split, cmp) and sort(split, end, cmp). Pad names with name.resize(8, ' ').

Expected output:

Name    Grade Status
Grace   95  PASS
Alice   92  PASS
Eve     88  PASS
Carol   75  PASS
Frank   60  PASS
Bob     58  FAIL
Dave    49  FAIL

Passed: 5, Failed: 2
