Chapter 12 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Write each program in a text editor or IDE, compile with g++ -std=c++17 -Wall -fsanitize=address, and test it. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Modernizing Raw Dynamic Arrays with std::unique_ptr<int[]> Easy

Given the following legacy C++ code using raw new[] and delete[]: 

int size = 5;
int* arr = new int[size];
for (int i = 0; i < size; ++i) arr[i] = (i + 1) * 10;
// Print elements and sum...
delete[] arr;

Rewrite the program to manage the dynamic array using std::unique_ptr<int[]> and std::make_unique. Fill the array with multiples of 10, calculate the sum and average, and verify that no manual delete[] is required.

Hint: Use std::make_unique<int[]>(size) and access elements via the standard operator[].

Expected output:

Array elements: 10 20 30 40 50
Sum: 150
Average: 30.0
Exercise 2 — Dynamic String Wrapper and Parameter Passing Easy

Write a program that:

  1. Creates a dynamically allocated std::string on the heap using std::make_unique<std::string>("Hello, Modern C++!").
  2. Passes the unique_ptr into a function inspectString(const std::string& str) that borrows the string by const reference without taking ownership.
  3. Passes the unique_ptr into a function modifyString(std::string& str) that appends " RAII is awesome." to it.
  4. Passes the unique_ptr by value using std::move() to a sink function consumeString(std::unique_ptr<std::string> ptr) that takes final ownership and prints its length.

Verify in main() that after consumeString, the original pointer is nullptr.

Expected output:

Inspecting: Hello, Modern C++!
Modified: Hello, Modern C++! RAII is awesome.
Consumed string of length 32: Hello, Modern C++! RAII is awesome.
Owner pointer is now null: true
Exercise 3 — Singly-Linked List with std::unique_ptr<Node> Medium

Implement a singly-linked list SmartList<T> where each Node holds its next pointer as std::unique_ptr<Node>: 

struct Node {
    T value;
    std::unique_ptr<Node> next;
    Node(T val) : value(move(val)), next(nullptr) {}
};

Implement the following member methods on SmartList<T>:

  • push_front(T value): Inserts a new node at the head of the list.
  • pop_front(): Removes the head node and returns true (or false if empty).
  • print() const: Traverses and prints all node values.
  • clear(): Iteratively pops all nodes to prevent deep recursive destructor stack overflow on very long lists.

Expected output:

List after pushes: 30 -> 20 -> 10 -> nullptr
Popped head.
List now: 20 -> 10 -> nullptr
Clearing remaining nodes...
List after clear: (empty)
Exercise 4 — RAII File Handler Class (FileHandle) Medium

Create a class FileHandle that wraps a standard C file stream (FILE*) using RAII principles:

  • Constructor: FileHandle(const char* filename, const char* mode) opens the file with fopen(). If opening fails, throws std::runtime_error.
  • Destructor: Closes the file with fclose() if valid, logging a message for debugging.
  • Non-copyable, Movable: Delete copy constructor and copy assignment; implement move constructor and move assignment.
  • Methods: write(const std::string& text), readLine() returning std::string, and isOpen() const.

Test writing a line to a temporary file "sample.txt" and reading it back.

Expected output:

[FileHandle] Opened 'sample.txt' for writing
[FileHandle] Wrote 25 bytes
[FileHandle] Closed 'sample.txt'
[FileHandle] Opened 'sample.txt' for reading
Read line: Hello RAII File Management!
[FileHandle] Closed 'sample.txt'
Exercise 5 — Building a Reference-Counted Smart Pointer (MySharedPtr<T>) Hard

Write your own simplified version of std::shared_ptr<T> called MySharedPtr<T> from scratch. Your class must manage:

  1. A raw pointer T* ptr_ to the heap resource.
  2. A pointer to a dynamically allocated reference counter size_t* ref_count_.

Implement:

  • Default constructor: Initializes ptr_ = nullptr and ref_count_ = nullptr.
  • Parametric constructor: explicit MySharedPtr(T* ptr) allocates new size_t(1).
  • Copy constructor: Shares the resource, incrementing *ref_count_.
  • Copy assignment operator: Decrements existing reference (deallocating if count hits 0) and shares rhs.
  • Move constructor & Move assignment operator: Transfers pointers without allocating or changing counts.
  • Destructor: Decrements count; if count reaches 0, deletes ptr_ and ref_count_.
  • Operators & helpers: operator*, operator->, use_count() const, get() const, and explicit operator bool() const.

Expected output:

Creating sp1...
sp1 use_count: 1, value: 42
Copying sp1 to sp2...
sp1 use_count: 2, sp2 use_count: 2
Inside nested scope:
sp3 created from sp2. use_count: 3
Exited nested scope.
sp1 use_count: 2
Moving sp2 to sp4...
sp2 is null: true, sp4 use_count: 2, value: 42
sp1 and sp4 leaving scope -> Resource cleaned up properly!
