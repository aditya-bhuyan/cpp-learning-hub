Chapter 10 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Write each program in a text editor or IDE, compile with g++ -std=c++17 -Wall, and test it. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Vector Statistics Easy

Read 10 integers from the user into a std::vector<int>. Then compute and print:

  • the sum
  • the average (as a double, 2 decimal places)
  • the minimum and maximum

Hint: Beware of integer division when computing the average, and seed min/max from the first element.

Expected output (sample):

Enter 10 integers: 4 8 15 16 23 42 1 7 9 30
Sum     : 155
Average : 15.50
Min     : 1
Max     : 42
Exercise 2 — Remove Duplicates with std::set Easy

Given vector<int> data = {5, 3, 8, 3, 1, 5, 9, 1, 8, 2};, use a std::set to remove the duplicates and print the unique values. What order do they come out in, and why?

Hint: A set can be constructed directly from a pair of iterators.

Expected output:

Original: 5 3 8 3 1 5 9 1 8 2
Unique  : 1 2 3 5 8 9
Exercise 3 — Phone Book with std::map Medium

Implement a phone book using std::map<std::string, std::string> (name → phone number) with three operations:

  • add(name, phone) — adds a contact, or updates the number if the name already exists
  • lookup(name) — prints the phone number, or "not found"
  • remove(name) — deletes the contact, reporting if it did not exist

Also print the full book in alphabetical order. Hint: a failed lookup should not create a new entry — which member functions guarantee that?

Expected output (sample):

Saved Alice.
Saved Charlie.
Saved Bob.
--- Phone book (3 entries) ---
  Alice -> 555-0101
  Bob -> 555-0202
  Charlie -> 555-0303
Bob: 555-0202
Zed not found.
Deleted Alice.
Alice not found.
Exercise 4 — Print Queue Simulation Medium

Use std::queue to simulate a printer. Define a PrintJob struct (id, document name, page count). Add four jobs, then process them in FIFO order, printing a line for each and a total page count at the end.

Expected output (sample):

Jobs waiting: 4

Printing job #1: report.pdf (12 pages)
Printing job #2: invoice.docx (2 pages)
Printing job #3: photo.png (1 pages)
Printing job #4: thesis.pdf (150 pages)

Queue empty. Total pages printed: 165
Exercise 5 — Graph BFS with an Adjacency List Hard

Represent a directed graph as std::map<std::string, std::vector<std::string>> (node → list of nodes it points to). Write:

  1. addEdge(graph, from, to)
  2. bfs(graph, start) that returns the nodes in breadth-first order, using std::queue for the frontier and a std::set for visited nodes

Test with edges A→B, A→C, B→D, C→D, D→E, F→A. Nodes unreachable from the start (like F) must not appear.

Hint: Mark a node as visited when you enqueue it, not when you dequeue it — otherwise a node can be queued twice.

Expected output:

Adjacency list:
  A -> B C
  B -> D
  C -> D
  D -> E
  E ->
  F -> A

BFS from A: A B C D E
