Chapter 06 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Work through each exercise in a text editor or IDE. Compile and run your program. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Pointer Swap Easy

Write a function swapInts(int* a, int* b) that takes two int* parameters and swaps the values at those addresses without using std::swap.

  1. Implement the function using a local temporary variable.
  2. In main(), declare two integers, print them, call swapInts, and print them again.

Expected output (sample):

Before: x=3, y=7
After : x=7, y=3
Exercise 2 — Array Traversal via Pointer Arithmetic Easy

Given the array int arr[] = {10, 20, 30, 40, 50};, print every element using pointer arithmetic only — do not use the subscript operator [] anywhere in the traversal loop.

Hint: Initialise a pointer to the start of the array and advance it with ++ptr. Use *ptr to read each element.

Expected output:

10 20 30 40 50
Exercise 3 — Pointer to Largest Element Medium

Implement a function int* maxElement(int* arr, int n) that returns a pointer to the largest element in the array of n integers.

  • Traverse the array using pointer arithmetic.
  • In main(), call the function on {4, 9, 2, 7, 5} and print both the value and the index of the maximum element.
  • Modify the maximum element through the returned pointer (set it to 0) and print the array again.

Expected output:

Max value = 9, index = 1
After zeroing: 4 0 2 7 5
Exercise 4 — Reverse Array In-Place Medium

Write a function reverseArray(int* arr, int n) that reverses the elements of an integer array in-place using pointer arithmetic (no subscript operator inside the function).

  • Use two pointers — one starting at the beginning and one at the end — and swap inward.
  • Test it on {1, 2, 3, 4, 5} and print the array before and after.

Expected output:

Before: 1 2 3 4 5
After : 5 4 3 2 1
Exercise 5 — Singly-Linked List with Pointers Hard

Define a struct Node that holds an int value and a pointer Node* next. Using only stack-allocated variables (no new):

  1. Create three Node variables: n1 (value 10), n2 (value 20), n3 (value 30).
  2. Link them: n1.next = &n2, n2.next = &n3, n3.next = nullptr.
  3. Write a function printList(Node* head) that traverses the list and prints each value separated by " -> ", followed by "nullptr".
  4. Call printList(&n1) from main().

Expected output:

10 -> 20 -> 30 -> nullptr

This exercise previews the linked-list data structure you will build dynamically in Chapter 12.
