Chapter 06 — Solutions

Reference solutions with explanations. Only read after attempting the exercises yourself.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Spoiler Warning These are reference solutions. There are often multiple valid approaches — if your output matches but your code differs, that is perfectly fine.
✅ Solution 1 — Pointer Swap

Swapping via pointers follows the classic three-step temporary-variable pattern. The caller passes the addresses of the variables; the function modifies the actual integers in the caller's stack frame through those pointers. 

// solution_06_swap.cpp
#include <iostream>
using namespace std;

void swapInts(int* a, int* b) {
    int temp = *a;  // save value at address a
    *a = *b;        // write value at b into address a
    *b = temp;      // write saved value into address b
}

int main() {
    int x = 3, y = 7;
    cout << "Before: x=" << x << ", y=" << y << "\n";
    swapInts(&x, &y);
    cout << "After : x=" << x << ", y=" << y << "\n";
    return 0;
}

Key concepts used: address-of operator, pointer parameters, dereference assignment.

✅ Solution 2 — Array Traversal via Pointer Arithmetic

The pointer starts at arr (which decays to &arr[0]). Pre-incrementing advances it one int-sized step each iteration. The sentinel condition ptr != arr + 5 stops at one-past-the-end — standard C++ idiom matching iterator-style loops. 

// solution_06_arithmetic.cpp
#include <iostream>
using namespace std;

int main() {
    int arr[] = {10, 20, 30, 40, 50};
    int n = 5;

    for (int* ptr = arr; ptr != arr + n; ++ptr) {
        cout << *ptr;
        if (ptr != arr + n - 1) cout << " ";
    }
    cout << "\n";
    return 0;
}

Key concepts used: pointer decay, pointer comparison, pre-increment on pointer.

✅ Solution 3 — Pointer to Largest Element

The function keeps a maxPtr tracking the current maximum. It compares values via *ptr > *maxPtr and updates accordingly. The returned pointer can be used both to read the value and — because it is a non-const pointer — to write a new value back to the array. 

// solution_06_maxelement.cpp
#include <iostream>
using namespace std;

int* maxElement(int* arr, int n) {
    int* maxPtr = arr;              // start: assume first is max
    for (int* p = arr + 1; p != arr + n; ++p) {
        if (*p > *maxPtr) {
            maxPtr = p;             // update to new maximum
        }
    }
    return maxPtr;
}

int main() {
    int arr[] = {4, 9, 2, 7, 5};
    int n = 5;

    int* m = maxElement(arr, n);
    cout << "Max value = " << *m
         << ", index = "  << (m - arr) << "\n";

    *m = 0;   // zero the maximum element through the returned pointer
    cout << "After zeroing: ";
    for (int* p = arr; p != arr + n; ++p) {
        cout << *p << " ";
    }
    cout << "\n";
    return 0;
}

Key concepts used: returning a pointer, pointer comparison, pointer difference for index.

✅ Solution 4 — Reverse Array In-Place

Two pointers, lo and hi, start at opposite ends of the array. Each iteration swaps the elements they point to, then converges inward. The loop ends when they meet or cross — the classic two-pointer reversal pattern. 

// solution_06_reverse.cpp
#include <iostream>
using namespace std;

void reverseArray(int* arr, int n) {
    int* lo = arr;            // pointer to first element
    int* hi = arr + n - 1;   // pointer to last element

    while (lo < hi) {
        // Swap via pointers (no subscript operator)
        int temp = *lo;
        *lo = *hi;
        *hi = temp;
        ++lo;
        --hi;
    }
}

void printArray(int* arr, int n) {
    for (int* p = arr; p != arr + n; ++p) {
        cout << *p;
        if (p != arr + n - 1) cout << " ";
    }
    cout << "\n";
}

int main() {
    int arr[] = {1, 2, 3, 4, 5};
    int n = 5;

    cout << "Before: "; printArray(arr, n);
    reverseArray(arr, n);
    cout << "After : "; printArray(arr, n);
    return 0;
}

Key concepts used: two-pointer technique, pointer increment/decrement, swap pattern.

✅ Solution 5 — Singly-Linked List with Pointers

A struct with a next pointer is the canonical building block of a linked list. Here all nodes live on the stack; the only heap-free requirement is that they outlive any traversal. The printList function follows next pointers until it reaches nullptr. 

// solution_06_linkedlist.cpp
#include <iostream>
using namespace std;

struct Node {
    int   value;
    Node* next;
};

void printList(Node* head) {
    Node* current = head;
    while (current != nullptr) {
        cout << current->value;
        if (current->next != nullptr) {
            cout << " -> ";
        }
        current = current->next;
    }
    cout << " -> nullptr\n";
}

int main() {
    // Stack-allocated nodes
    Node n3 = {30, nullptr};
    Node n2 = {20, &n3};
    Node n1 = {10, &n2};

    printList(&n1);   // 10 -> 20 -> 30 -> nullptr

    return 0;
}

Key concepts used: struct with pointer member, address-of to link nodes, pointer traversal with -> member access operator, nullptr sentinel.

Arrow operator ->: current->value is shorthand for (*current).value — dereference the pointer, then access the member. Always use -> when accessing struct/class members through a pointer.
