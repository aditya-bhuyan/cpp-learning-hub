Chapter 09 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Work through each exercise in a text editor or IDE. Compile and run your program. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Template Swap Function Easy

Write a function template mySwap<T> that swaps the values of two variables of any type using a temporary variable. Do not use std::swap.

Test your function with:

  • Two int variables: a = 10, b = 20
  • Two double variables: x = 1.5, y = 9.9
  • Two std::string variables: s1 = "hello", s2 = "world"

Print the values before and after each swap.

Expected output (sample):

Before: a=10, b=20   After: a=20, b=10
Before: x=1.5, y=9.9   After: x=9.9, y=1.5
Before: s1=hello, s2=world   After: s1=world, s2=hello

Hint: The function signature is template<typename T> void mySwap(T& a, T& b). Note the references — without them, swapping will have no effect on the original variables.

Exercise 2 — Generic Array Printer Easy

Write a function template printArray<T>(T arr[], int size) that prints every element of a C-style array separated by spaces, followed by a newline.

Test it with:

  • An int array: {5, 10, 15, 20, 25}
  • A double array: {1.1, 2.2, 3.3}
  • A char array: {'C', '+', '+'}

Expected output:

5 10 15 20 25
1.1 2.2 3.3
C + +

Hint: The template parameter T is deduced from the array element type. You need the explicit int size parameter because C-style arrays decay to a pointer — the compiler cannot deduce the size.

Exercise 3 — Generic Queue<T> Class Template Medium

Implement a class template Queue<T> that models a first-in, first-out (FIFO) container. Use a std::deque<T> or std::vector<T> internally.

The class must provide the following public members:

  • void enqueue(const T& value) — add an element to the back
  • void dequeue() — remove the front element (throw std::underflow_error if empty)
  • T& front() — return a reference to the front element without removing it
  • bool isEmpty() const — return true if the queue is empty
  • int size() const — return the number of elements

Write a main() that creates a Queue<int>, enqueues 1–5, then dequeues and prints each element to confirm FIFO order. Also test exception throwing on an empty queue.

Expected output (sample):

Enqueued: 1 2 3 4 5
Dequeued: 1 2 3 4 5
Caught: dequeue() called on empty queue
Exercise 4 — Template Function: Index of Minimum Element Medium

Write a function template indexOfMin<T>(T arr[], int size) that searches a C-style array and returns the index of the minimum element. Use operator < for comparison.

Test with:

  • int array: {42, 7, 99, 3, 18} — expected index: 3
  • double array: {5.5, 1.1, 8.8, 0.5, 3.3} — expected index: 3
  • char array: {'d', 'a', 'c', 'b'} — expected index: 1

Print both the index and the minimum value for each test.

Expected output:

int array   — min index=3, value=3
double array — min index=3, value=0.5
char array  — min index=1, value=a

Hint: Initialise a minIdx = 0 and loop from index 1 to size-1, updating minIdx whenever arr[i] < arr[minIdx].

Exercise 5 — Generic Matrix<T, ROWS, COLS> with Non-Type Parameters Hard

Implement a class template Matrix<T, ROWS, COLS> using non-type template parameters for the dimensions. The class must:

  • Store elements internally in a 2D array: T data_[ROWS][COLS]
  • Default-construct all elements to T{} (zero for numeric types)
  • Provide T& at(int row, int col) — bounds-checked element access
  • Provide void print(const std::string& label = "") const — display the matrix row by row
  • Provide Matrix<T, ROWS, COLS> add(const Matrix<T, ROWS, COLS>& other) const — return a new matrix that is the element-wise sum of *this and other

In main(), create two Matrix<int, 2, 3> objects, populate them, add them, and print each result. Then also create a Matrix<double, 3, 3> to demonstrate re-use with a different type and size.

Expected output (sample):

Matrix A:
  1  2  3
  4  5  6
Matrix B:
  7  8  9
 10 11 12
A + B:
  8 10 12
 14 16 18

Hint: The template signature is template<typename T, int ROWS, int COLS>. The add() method should iterate with nested loops and use at() or direct array access.
