Chapter 03 — Control Flow

Make decisions and repeat work: conditionals, switch, every kind of loop, and the jump statements that steer them.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz

3.1 What is Control Flow?

By default a C++ program executes statements one after another, from the top of main() to the bottom. Control-flow statements change that default order. They let a program choose between alternatives (selection) and repeat a block of code (iteration). Together with sequential execution, these two ideas are enough to express any algorithm.

CategoryStatementsPurpose
Selectionif, if/else, ?:, switchChoose which code runs
Iterationfor, range-for, while, do-whileRun code repeatedly
Jumpbreak, continue, goto, returnTransfer control elsewhere

3.2 The if Statement

An if statement evaluates a condition. If it is true (any non-zero value converts to true), the controlled statement runs; otherwise it is skipped. 

// Syntax:
// if (condition) {
//     statements;
// }

#include <iostream>
using namespace std;

int main() {
    int temperature = 35;

    // The block runs only when the condition evaluates to true
    if (temperature > 30) {
        cout << "It's a hot day!\n";
    }

    cout << "This line always runs.\n";
    return 0;
}
Warning — = versus == if (x = 5) assigns 5 to x and then tests the result (always true). You almost certainly meant if (x == 5). Compile with -Wall so the compiler warns you.
Tip — always use braces A braceless if controls only the next single statement. Adding a second line later without adding braces is a classic bug. Using { } every time costs nothing and prevents it.

3.3 if / else

Add an else branch to run code when the condition is false. Exactly one of the two branches executes.

int age = 16;

if (age >= 18) {
    cout << "You may vote.\n";
} else {
    cout << "You are too young to vote.\n";
}

3.4 if / else if / else Chains

When there are more than two alternatives, chain conditions with else if. The conditions are tested top to bottom; the first one that is true wins and the rest are skipped. The final else is an optional catch-all. 

int score = 82;
char grade;

if (score >= 90) {
    grade = 'A';
} else if (score >= 80) {      // only reached when score < 90
    grade = 'B';
} else if (score >= 70) {      // only reached when score < 80
    grade = 'C';
} else if (score >= 60) {
    grade = 'D';
} else {                        // everything else
    grade = 'F';
}

cout << "Grade: " << grade << "\n";   // Grade: B
Order matters Because the first true condition wins, test the most specific or restrictive conditions first. Putting score >= 60 first would make every passing score a "D".

3.5 Nested if Statements

An if can appear inside another if (or else) to test a second condition only when the first holds.

int age = 25;
bool hasLicense = true;

if (age >= 18) {
    if (hasLicense) {
        cout << "You may drive.\n";
    } else {
        cout << "Get a licence first.\n";
    }
} else {
    cout << "You are too young to drive.\n";
}

When to avoid deep nesting

Every extra nesting level makes code harder to read and reason about (the "arrow anti-pattern"). Prefer logical operators or early exits (guard clauses) to flatten the structure. 

// Flattened with &&
if (age >= 18 && hasLicense) {
    cout << "You may drive.\n";
}

// Guard-clause style inside a function: reject bad input first,
// then keep the "happy path" un-indented.
int safeDivide(int a, int b) {
    if (b == 0) {
        cout << "Error: division by zero\n";
        return 0;               // early exit
    }
    return a / b;               // main logic stays at the top level
}
Rule of thumb If you find yourself indenting more than three levels, stop and ask whether combined conditions, early return/continue, or a helper function would make the code flatter.

3.6 The Ternary (Conditional) Operator

The ternary operator is C++'s only three-operand operator. It is a compact, expression form of if/else that produces a value: 

// Syntax:   condition ? true_expr : false_expr

int a = 12, b = 20;

// Equivalent if/else version:
int larger;
if (a > b) { larger = a; } else { larger = b; }

// Ternary version — one line, and it can initialise a const:
const int maxVal = (a > b) ? a : b;

cout << "Max is " << maxVal << "\n";                     // Max is 20
cout << (a % 2 == 0 ? "a is even" : "a is odd") << "\n"; // a is even
Warning — keep it readable Nesting ternaries (a ? b : c ? d : e) quickly becomes unreadable. Use the ternary for simple two-way choices and switch to if/else for anything more involved. Both result expressions should also have compatible types.

3.7 The switch Statement

switch selects one of many code paths by comparing an integral or enumeration expression (int, char, enum, …) against constant case labels. It cannot switch on double or std::string. 

int day = 3;

switch (day) {
    case 1:
        cout << "Monday\n";
        break;                  // leave the switch
    case 2:
        cout << "Tuesday\n";
        break;
    case 3:
        cout << "Wednesday\n"; // <-- matches; prints this
        break;
    default:                    // runs if no case matches
        cout << "Some other day\n";
        break;
}
  • case labels must be compile-time constants and unique.
  • break exits the switch. Without it execution continues into the next case (fall-through).
  • default is optional and handles every value not matched by a case. It may appear anywhere, but placing it last is conventional.

Fall-through behaviour

If a case has no break, control "falls through" and executes the statements of the following case, regardless of that case's label. Occasionally this is useful for grouping labels: 

char ch = 'e';

switch (ch) {
    case 'a':
    case 'e':
    case 'i':
    case 'o':
    case 'u':                   // all five vowels share one body
        cout << ch << " is a vowel\n";
        break;
    default:
        cout << ch << " is a consonant\n";
}

// ACCIDENTAL fall-through (a bug):
int n = 1;
switch (n) {
    case 1: cout << "one\n";    // missing break!
    case 2: cout << "two\n";    // also runs
    case 3: cout << "three\n"; break;
}
// Output: one / two / three
Warning — forgotten break Accidental fall-through is one of the most common switch bugs. If you fall through on purpose, mark it with the C++17 attribute [[fallthrough]]; so readers and compilers know it is intentional. Also, declaring a variable inside a case usually requires wrapping that case body in its own { } block.

3.8 The for Loop

The for loop is ideal when you know in advance how many times to iterate. It packs three parts into its header:

// for (initialization; condition; update) {
//     body;
// }

for (int i = 1; i <= 5; i++) {
    cout << i << " ";
}
// Output: 1 2 3 4 5
PartExampleWhen it runs
Initializationint i = 1Once, before the first iteration. A variable declared here is scoped to the loop.
Conditioni <= 5Before every iteration. If false, the loop ends.
Updatei++After every iteration of the body, before the condition is re-tested.

Execution order: init → (condition → body → update) repeated until the condition is false. Any part may be omitted; for (;;) is an infinite loop.

// Counting down
for (int i = 10; i > 0; i--) cout << i << " ";

// Stepping by 2
for (int i = 0; i <= 20; i += 2) cout << i << " ";

// Multiple variables with the comma operator
for (int lo = 0, hi = 9; lo < hi; lo++, hi--) {
    cout << lo << "-" << hi << "\n";
}
Warning — off-by-one errors i < 5 runs 5 times starting from 0 (0–4); i <= 5 runs 6 times. Decide whether your bound is inclusive or exclusive and check the first and last iterations by hand.

3.9 Range-Based for Loop (C++11)

The range-based for iterates over every element of an array or container without an index, eliminating a whole class of bounds mistakes. 

#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> nums = {10, 20, 30, 40};

    // Copy of each element (modifying x does NOT change the vector)
    for (auto x : nums) cout << x << " ";
    cout << "\n";

    // Reference — modifies the elements in place
    for (auto& x : nums) x *= 2;

    // const reference — read-only, no copy (best for large objects)
    for (const auto& x : nums) cout << x << " ";   // 20 40 60 80
    cout << "\n";

    // Works on built-in arrays and initializer lists too
    int arr[] = {1, 2, 3};
    for (int v : arr) cout << v << " ";
    return 0;
}
Tip — choose the right form Use auto x for cheap types like int, const auto& x for read-only access to larger types such as std::string, and auto& x when you need to modify elements.

3.10 The while Loop (Pre-condition)

A while loop tests its condition before each iteration. If the condition is false the first time, the body never runs. Use it when the number of iterations is not known in advance. 

// Syntax: while (condition) { body; }

int n = 12345;
int digits = 0;

while (n != 0) {        // tested BEFORE each pass
    n /= 10;            // drop the last digit
    digits++;
}
cout << "Digits: " << digits << "\n";   // Digits: 5

int count = 10;
while (count < 5) {     // false immediately — body never executes
    cout << "never printed\n";
}
Warning — infinite loops Make sure something inside the body eventually makes the condition false (changing a variable, reading new input, or using break). Forgetting n /= 10; above would loop forever.

3.11 The do-while Loop (Post-condition)

A do-while loop tests its condition after the body, so the body executes at least once, even if the condition is false from the start. Note the required semicolon at the end. 

// Syntax:
// do {
//     body;
// } while (condition);      <-- semicolon is mandatory

int choice;
do {
    cout << "Enter a number from 1 to 5: ";
    cin  >> choice;
} while (choice < 1 || choice > 5);   // repeat while input is invalid

// Body runs exactly once although the condition is false immediately:
int x = 100;
do {
    cout << "x = " << x << "\n";     // prints once
} while (x < 5);
Featurewhiledo-while
Condition checkedBefore the bodyAfter the body
Minimum executions01
Typical useUnknown count, may be zeroMenus, input validation

3.12 break — Exit a Loop Early

break immediately terminates the innermost enclosing loop (or switch). Execution continues with the first statement after that loop. 

// Find the first multiple of 7 above 50
for (int i = 51; i < 1000; i++) {
    if (i % 7 == 0) {
        cout << "Found: " << i << "\n";   // Found: 56
        break;                              // stop searching
    }
}

// Typical use: an intentionally infinite loop with an exit condition
while (true) {
    int v;
    cin >> v;
    if (v == 0) break;       // sentinel value ends the loop
    cout << "Got " << v << "\n";
}

3.13 continue — Skip the Current Iteration

continue skips the rest of the current iteration and jumps straight to the next one. In a for loop, the update expression still runs; in while/do-while, control goes to the condition test. 

// Print only odd numbers from 1 to 10
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) {
        continue;           // skip even numbers
    }
    cout << i << " ";       // 1 3 5 7 9
}
Warning — continue in while loops In a while loop, make sure the variable that changes the condition is updated before the continue; otherwise you skip the update and create an infinite loop.

3.14 goto — Why It Exists and Why to Avoid It

goto label; performs an unconditional jump to a labelled statement in the same function. It exists for historical reasons (C and early languages had few structured constructs) and because it is occasionally handy for escaping several nested loops or for centralised clean-up in C-style code. 

// Escaping two nested loops at once
for (int i = 0; i < 5; i++) {
    for (int j = 0; j < 5; j++) {
        if (i * j == 6) {
            cout << "Found at i=" << i << ", j=" << j << "\n";
            goto done;              // jump out of BOTH loops
        }
    }
}
done:                               // label
cout << "Search finished.\n";

Why you should generally avoid it:

  • It produces "spaghetti code" where the execution path is hard to follow and verify.
  • It cannot jump over initialisations of variables into their scope, and it bypasses destructors' normal flow in subtle ways, limiting its safety in C++.
  • Structured alternatives are clearer: break with a flag variable, return from a helper function, or RAII for clean-up.
Better alternative Move the nested loops into a function and use return to leave them all at once. It is just as short and far easier to maintain than goto.

3.15 Nested Loops and Loop Patterns

A loop inside another loop is a nested loop. For each iteration of the outer loop, the inner loop runs to completion. If the outer loop runs m times and the inner n times, the inner body runs m × n times. Nested loops are the natural tool for rows and columns.

Right-angled triangle

int rows = 5;
for (int i = 1; i <= rows; i++) {          // outer loop: one pass per row
    for (int j = 1; j <= i; j++) {         // inner loop: i stars in row i
        cout << "* ";
    }
    cout << "\n";                         // end the row
}
/* Output:
*
* *
* * *
* * * *
* * * * *
*/

Multiplication table

#include <iomanip>   // std::setw

for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= 5; j++) {
        cout << setw(4) << i * j;     // right-align each value in 4 columns
    }
    cout << "\n";
}
/* Output:
   1   2   3   4   5
   2   4   6   8  10
   3   6   9  12  15
   4   8  12  16  20
   5  10  15  20  25
*/

Inverted triangle

for (int i = 5; i >= 1; i--) {
    for (int j = 1; j <= i; j++) {
        cout << "# ";
    }
    cout << "\n";
}
Pattern-printing recipe 1) Decide how many rows (outer loop). 2) For each row, work out how many spaces and how many symbols are needed as a function of the row number. 3) Use one inner loop per kind of output, then print a newline after each row. Note that break and continue affect only the innermost loop.

3.16 Choosing the Right Construct

SituationBest choice
Two alternativesif / else (or ternary for a simple value)
Many alternatives on one integral valueswitch
Ranges or complex boolean conditionsif / else if chain
Known number of iterationsfor
Visit every element of a containerrange-based for
Unknown number of iterations, may be zerowhile
Must run at least once (menus, validation)do-while

3.17 Key Takeaways

  • if / else if / else tests conditions top to bottom; the first true branch runs.
  • Avoid deep nesting with &&, ||, and early exits.
  • The ternary cond ? a : b is an expression that yields a value; keep it simple.
  • switch needs break to prevent fall-through; always consider a default.
  • for = initialization; condition; update. Use it when the count is known.
  • Range-based for (C++11) is the safest way to walk a container.
  • while checks first (0+ runs); do-while checks last (1+ runs).
  • break leaves the loop; continue skips to the next iteration; avoid goto.
  • Nested loops multiply iteration counts and are the basis of patterns and tables.
