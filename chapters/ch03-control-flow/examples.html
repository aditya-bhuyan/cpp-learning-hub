Chapter 03 — Coding Examples

Four fully commented programs that put conditionals, loops, and switch to work.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz

Example 1 — FizzBuzz (1–100)

A classic interview warm-up. For each number from 1 to 100: print FizzBuzz if it is divisible by both 3 and 5, Fizz if divisible by 3, Buzz if divisible by 5, otherwise the number itself. It demonstrates an if / else if / else chain where order matters. 

// fizzbuzz.cpp
// Compile: g++ -std=c++17 -Wall -o fizzbuzz fizzbuzz.cpp
// Run:     ./fizzbuzz

#include <iostream>
using namespace std;

int main() {
    // The for loop visits every number from 1 to 100 inclusive
    for (int i = 1; i <= 100; i++) {

        // The combined test MUST come first. A multiple of 15 is also a
        // multiple of 3 and 5, so testing those first would hide FizzBuzz.
        if (i % 15 == 0) {
            cout << "FizzBuzz";
        } else if (i % 3 == 0) {
            cout << "Fizz";
        } else if (i % 5 == 0) {
            cout << "Buzz";
        } else {
            cout << i;             // none of the rules matched
        }

        cout << "\n";               // one result per line
    }

    return 0;
}

Expected output (first 15 lines):

1
2
Fizz
4
Buzz
Fizz
7
8
Fizz
Buzz
11
Fizz
13
14
FizzBuzz
Why i % 15? A number divisible by both 3 and 5 is divisible by their least common multiple, 15. Writing i % 3 == 0 && i % 5 == 0 is equivalent and may read more clearly to a beginner.

Example 2 — Number Pyramid with Nested Loops

Prints a centred pyramid whose rows count up to the row number and back down again (1, 121, 12321, …). Each row uses three inner loops: one for leading spaces, one for the ascending digits, and one for the descending digits. 

// pyramid.cpp
// Compile: g++ -std=c++17 -Wall -o pyramid pyramid.cpp

#include <iostream>
using namespace std;

int main() {
    int rows;
    cout << "Enter number of rows (1-9): ";
    cin  >> rows;

    // Outer loop: i is the current row, 1..rows
    for (int i = 1; i <= rows; i++) {

        // 1) Leading spaces push the row towards the centre.
        //    Row 1 needs (rows-1) spaces, the last row needs 0.
        for (int s = 1; s <= rows - i; s++) {
            cout << ' ';
        }

        // 2) Ascending digits: 1, 2, ... i
        for (int j = 1; j <= i; j++) {
            cout << j;
        }

        // 3) Descending digits: i-1, i-2, ... 1
        for (int j = i - 1; j >= 1; j--) {
            cout << j;
        }

        cout << '\n';               // finish the row
    }

    return 0;
}

Sample session:

Enter number of rows (1-9): 5
    1
   121
  12321
 1234321
123454321
How the pattern is derived Row i has rows − i spaces and 2i − 1 digits. Working out these two formulas on paper before coding is the key to every pattern-printing problem.

Example 3 — Prime Number Checker (while + break)

A number greater than 1 is prime if its only divisors are 1 and itself. We test candidate divisors from 2 upward with a while loop and use break to stop at the first divisor found. We only need to test divisors up to the square root of n, because divisors come in pairs. 

// prime_checker.cpp
// Compile: g++ -std=c++17 -Wall -o prime_checker prime_checker.cpp

#include <iostream>
using namespace std;

int main() {
    int n;
    cout << "Enter an integer: ";
    cin  >> n;

    bool isPrime = true;          // assume prime until proven otherwise

    if (n < 2) {
        isPrime = false;          // 0, 1 and negatives are not prime
    } else {
        int d = 2;                // first candidate divisor

        // d * d <= n is the same as d <= sqrt(n) without needing <cmath>
        while (d * d <= n) {
            if (n % d == 0) {     // found a divisor
                isPrime = false;
                break;            // no need to look any further
            }
            d++;                  // try the next candidate
        }
    }

    if (isPrime) {
        cout << n << " is a prime number.\n";
    } else {
        cout << n << " is not a prime number.\n";
    }

    return 0;
}

Sample sessions:

Enter an integer: 29
29 is a prime number.

Enter an integer: 91
91 is not a prime number.
Why break matters For n = 1000000 the loop stops at d = 2 instead of checking about a thousand divisors. Leaving a loop as soon as the answer is known is a common and valuable optimisation.

Example 4 — Menu-Driven Calculator (switch + do-while)

A menu must be shown at least once, which is exactly what do-while guarantees. Inside the loop a switch dispatches on the user's choice. The program ends when the user picks option 5. 

// calculator.cpp
// Compile: g++ -std=c++17 -Wall -o calculator calculator.cpp

#include <iostream>
using namespace std;

int main() {
    int choice;

    do {
        // ---- Show the menu (runs at least once) ----
        cout << "\n===== Calculator Menu =====\n";
        cout << "1. Add\n";
        cout << "2. Subtract\n";
        cout << "3. Multiply\n";
        cout << "4. Divide\n";
        cout << "5. Exit\n";
        cout << "Choose an option: ";
        cin  >> choice;

        // Options 1-4 need two operands; read them only when needed
        double a = 0, b = 0;
        if (choice >= 1 && choice <= 4) {
            cout << "Enter two numbers: ";
            cin  >> a >> b;
        }

        // ---- Dispatch on the choice ----
        switch (choice) {
            case 1:
                cout << a << " + " << b << " = " << (a + b) << "\n";
                break;                    // without break we would fall into case 2
            case 2:
                cout << a << " - " << b << " = " << (a - b) << "\n";
                break;
            case 3:
                cout << a << " * " << b << " = " << (a * b) << "\n";
                break;
            case 4:
                if (b == 0) {             // guard against division by zero
                    cout << "Error: cannot divide by zero.\n";
                } else {
                    cout << a << " / " << b << " = " << (a / b) << "\n";
                }
                break;
            case 5:
                cout << "Goodbye!\n";
                break;
            default:                      // any other number
                cout << "Invalid option. Please choose 1-5.\n";
                break;
        }

    } while (choice != 5);                // loop until the user chooses Exit

    return 0;
}
