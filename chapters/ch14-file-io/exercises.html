Chapter 14 — Exercises

Apply what you've learned. Attempt each problem before viewing the solutions.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz
Instructions Write each program in a text editor or IDE, compile with g++ -std=c++17 -Wall, and test it against the sample input. Only open Solutions after you have made a genuine attempt.
Exercise 1 — Sum & Average of Numbers from File Easy

Write a program that:

  1. Creates an output file named numbers.txt and writes 10 integers into it (e.g. separated by spaces or newlines).
  2. Closes the output stream.
  3. Opens numbers.txt with an ifstream and reads the integers in a loop using while (in >> num).
  4. Calculates and displays the count of numbers read, the total sum, and the average (as a double with 2 decimal places).

Hint: Cast the sum or count to double before division to avoid integer truncation.

Expected output (sample):

Wrote 10 integers to numbers.txt
Read 10 numbers: 15 28 42 7 91 33 64 50 82 18
Sum     = 430
Average = 43.00
Exercise 2 — File Copy Utility Easy

Write a robust command-line file copy function: bool copyFile(const std::string& sourcePath, const std::string& destPath).

  • Open the source file in binary mode (std::ios::binary) to handle all file types (text, images, PDFs).
  • Check if the source file opened successfully. If not, print an error message and return false.
  • Open the destination file in binary write mode (std::ios::binary). If opening fails, return false.
  • Copy content efficiently using a buffer (or stream buffer insertion dest << src.rdbuf() / block read/write).
  • Return true upon successful copy and display the total number of bytes transferred.

Expected output (sample):

Source file: origin.txt (Created with test data)
Copying origin.txt -> backup.txt...
Success: Copied 128 bytes to backup.txt
Exercise 3 — INI/Config File Parser (std::map) Medium

Implement a configuration file loader: std::map<std::string, std::string> loadConfig(const std::string& filename).

The parser must:

  1. Read a text file line-by-line using std::getline().
  2. Ignore empty lines or lines containing only whitespace.
  3. Ignore comment lines (lines starting with # or ;).
  4. For valid lines formatted as KEY=VALUE, split the key and value around the first = character, trim leading/trailing whitespace from both, and store them into the map.

Demonstrate your parser by loading a sample config file and querying specific keys.

Expected output (sample):

--- Loaded Config (5 settings) ---
database_host = localhost
database_port = 5432
max_connections = 100
server_name = AlphaCluster
timeout_seconds = 30

Lookup 'database_host': localhost
Lookup 'max_connections': 100
Lookup 'ssl_enabled': [Not configured]
Exercise 4 — Grade Book Report Generator Medium

Write a program that processes student test scores from an input file and generates an executive summary report in an output file.

  • Create an input file grades.txt where each line contains: StudentName Score (e.g., Alice 88, Bob 54).
  • Read all student records from grades.txt into a vector of structs.
  • Determine pass/fail status for each student (passing threshold: score ≥ 60.0).
  • Compute the class average, highest score, and lowest score.
  • Write a formatted summary report to report.txt with aligned columns, status indicators, and summary metrics. Also echo the report to the console.

Expected output (sample in report.txt):

========================================
           GRADE BOOK REPORT
========================================
Student Name        Score    Status
----------------------------------------
Alice               88.50    PASS
Bob                 54.00    FAIL
Charlie             92.00    PASS
Diana               76.50    PASS
Evan                48.00    FAIL
----------------------------------------
Total Students : 5
Class Average  : 71.80
Highest Score  : 92.00 (Charlie)
Lowest Score   : 48.00 (Evan)
Passing Rate   : 60.0% (3/5)
========================================
Exercise 5 — Binary Index & Random Access with seekg Hard

Build a random-access binary database for a store inventory:

  1. Define a POD struct Product with fields: int id, char name[32], double price, and int stock.
  2. Write an array of 5 distinct products to a binary file inventory.dat using out.write().
  3. Close the write stream.
  4. Open inventory.dat with an ifstream in ios::binary mode.
  5. Compute the total number of records in the file using tellg() and seekg(0, ios::end).
  6. Implement direct random access: jump directly to the 3rd product (zero-based index 2) using:
    in.seekg(2 * sizeof(Product), std::ios::beg)
    Read only that single struct into memory and display its details without iterating through records 0 and 1.
  7. Update in-place: open with fstream in ios::in | ios::out | ios::binary, seek to the 3rd product's position with seekp(), modify its stock count, write it back, and read it again to verify the in-place update.

Expected output:

Wrote 5 products to binary file inventory.dat (240 total bytes).
Total records detected: 5

[Random Access] Directly reading Record #3 (offset: 96 bytes)...
Loaded Product: ID 303 | Name: Mechanical Keyboard | Price: $89.99 | Stock: 15

[In-Place Update] Updating Record #3 stock to 45...
Verified Record #3 after update:
Loaded Product: ID 303 | Name: Mechanical Keyboard | Price: $89.99 | Stock: 45
