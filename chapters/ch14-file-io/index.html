Chapter 14 — File I/O

Stream-based file handling in C++ — formatted I/O, binary serialization, stream positioning, state handling, and the C++17 filesystem library.

📖 Learning 💻 Examples ✏️ Exercises ✅ Solutions 🧠 Quiz

14.1 The <fstream> Header & Stream Hierarchy

In C++, file input and output are performed using file stream classes defined in the <fstream> standard header. Just as std::cin and std::cout provide stream interfaces for keyboard and console, file streams provide the same stream semantics for files on disk.

Header #include <fstream>

The three core stream classes provided by <fstream> are:

ClassPurposeDefault DirectionInherits From
std::ofstreamOutput file stream (writing files)Write only (ios::out)std::ostream
std::ifstreamInput file stream (reading files)Read only (ios::in)std::istream
std::fstreamBidirectional file stream (reading and writing)Read & Write (ios::in | ios::out)std::iostream

Because ifstream inherits from istream and ofstream inherits from ostream, any function written to take a std::istream& or std::ostream& can seamlessly operate on file streams, console streams (cin/cout), or string streams (stringstream).

14.2 Opening Files & Open Modes

A file stream can be opened in two ways:

  1. Via constructor: Pass the filename and optional open mode flags directly when instantiating the stream object.
  2. Via the open() member function: Instantiate first, then call open(filename, mode).
#include <fstream>
#include <string>

// Method 1: Constructor (preferred — ties lifetime to file access)
std::ofstream outFile("log.txt", std::ios::app);

// Method 2: Separate open()
std::ifstream inFile;
inFile.open("data.txt", std::ios::in);

Open Mode Flags (std::ios)

File streams take mode flags from the std::ios namespace that specify how the file is accessed. Multiple flags can be combined using the bitwise OR operator (|):

Mode FlagDescription
std::ios::inOpen for input operations (reading). Default for ifstream.
std::ios::outOpen for output operations (writing). Default for ofstream (truncates existing file).
std::ios::appAppend mode — all write operations occur at the end of the file. Existing content is preserved.
std::ios::ate"At end" — opens the file and immediately positions the stream pointer at the end of the file.
std::ios::truncTruncate mode — if the file exists, discard its previous contents (truncate to 0 bytes).
std::ios::binaryBinary mode — prevents OS-specific translation of newlines (e.g. \r\n to \n on Windows).

Common Mode Combinations

  • ios::out | ios::trunc: Overwrite file (default for ofstream).
  • ios::out | ios::app: Append to existing file without overwriting.
  • ios::in | ios::out: Read and write without truncating existing content.
  • ios::in | ios::out | ios::trunc: Open for reading and writing, truncating existing content.
  • ios::in | ios::binary: Read binary data.
  • ios::out | ios::binary: Write binary data.

14.3 Checking if a File Opened Successfully

Attempting to read from or write to an unopened file will silently fail and set the stream's error state. Always verify that the file opened successfully before attempting I/O operations. 

#include <iostream>
#include <fstream>

int main() {
    std::ifstream file("config.ini");

    // Method A: Using operator bool / if (!file)
    if (!file) {
        std::cerr << "Error: Could not open file (operator bool check failed)!\n";
        return 1;
    }

    // Method B: Using is_open()
    if (!file.is_open()) {
        std::cerr << "Error: File is not open!\n";
        return 1;
    }

    std::cout << "File opened successfully.\n";
    return 0;
}
Difference between !file and !file.is_open() file.is_open() strictly tests whether the stream is associated with an open file on the filesystem. !file (boolean conversion) checks whether any error bit (failbit or badbit) is set, which includes open failures as well as subsequent read/write format failures.

14.4 Writing Text Files

Writing text to an ofstream uses the stream insertion operator (<<), exactly like std::cout. You can format output with manipulators from <iomanip>. 

#include <iostream>
#include <fstream>
#include <iomanip>

int main() {
    std::ofstream out("scores.txt");
    if (!out) {
        std::cerr << "Failed to create scores.txt\n";
        return 1;
    }

    out << "Player,Score,Accuracy\n";
    out << "Alice," << 9500 << "," << std::fixed << std::setprecision(2) << 98.45 << "\n";
    out << "Bob," << 8200 << "," << std::fixed << std::setprecision(2) << 91.20 << "\n";

    // Destructor closes the file automatically (RAII)
    return 0;
}

14.5 Reading Text Files

There are three primary techniques for reading text data from an ifstream:

1. Reading Formatted Tokens with operator>>

Reads whitespace-delimited tokens (words, numbers) and automatically parses them into the target variable type: 

std::ifstream in("numbers.txt");
int num;
while (in >> num) {
    std::cout << "Read integer: " << num << "\n";
}

2. Reading Line-by-Line with std::getline()

Reads an entire line up to the newline character '\n' into a std::string: 

std::ifstream in("document.txt");
std::string line;
int lineNum = 1;
while (std::getline(in, line)) {
    std::cout << lineNum++ << ": " << line << "\n";
}

3. Reading Character-by-Character with get()

Reads raw individual characters, preserving whitespace and newlines: 

std::ifstream in("source.txt");
char ch;
while (in.get(ch)) {
    std::cout.put(ch);
}

14.6 Stream State & Error Handling

Every stream maintains an internal state consisting of four status flags:

MethodFlag CheckedMeaning
good()None set (0)Everything is fine; stream is ready for I/O operations.
eof()eofbitThe stream reached the End-Of-File during a read operation.
fail()failbit / badbitA formatting error or logical I/O failure occurred (e.g. reading text into an int).
bad()badbitA severe, unrecoverable I/O error occurred (e.g. disk corruption, hardware fault).
clear()Resets flagsResets the error state flags to goodbit so further operations can be attempted.
The Classic while (!file.eof()) Bug file.eof() only becomes true after an input operation attempts to read past the end of the file and fails. If you test while (!file.eof()) before reading, the loop body will execute one extra time on EOF, processing garbage or duplicate data.

Always write: while (file >> x) or while (std::getline(file, line)) — this tests whether the read operation actually succeeded!

Enabling Stream Exceptions

By default, stream errors set error bits rather than throwing exceptions. You can instruct a stream to throw std::ios_base::failure on errors using exceptions(): 

#include <fstream>
#include <iostream>

int main() {
    std::ifstream file;
    // Configure file to throw on failbit or badbit
    file.exceptions(std::ifstream::failbit | std::ifstream::badbit);

    try {
        file.open("non_existent_file.txt");
    } catch (const std::ios_base::failure& e) {
        std::cerr << "I/O Exception caught: " << e.what() << "\n";
    }
    return 0;
}

14.7 File Positioning & Random Access

C++ streams track separate read (get) and write (put) file position pointers:

  • Get pointer (input):
    • tellg(): Returns current read position as a std::streampos.
    • seekg(offset, origin) or seekg(pos): Moves the read pointer.
  • Put pointer (output):
    • tellp(): Returns current write position as a std::streampos.
    • seekp(offset, origin) or seekp(pos): Moves the write pointer.

Seek Origins

Origin FlagDescription
std::ios::begOffset from the beginning of the stream (default).
std::ios::curOffset from the current position.
std::ios::endOffset from the end of the stream (typically negative offset).

Example: Determining File Size via seekg

#include <iostream>
#include <fstream>

std::streampos getFileSize(const std::string& filename) {
    std::ifstream file(filename, std::ios::binary | std::ios::ate);
    if (!file) return -1;
    return file.tellg(); // Opened at end -> tellg gives byte size
}

int main() {
    std::cout << "File size: " << getFileSize("data.bin") << " bytes\n";
    return 0;
}

14.8 Closing Files & RAII

File stream destructors automatically flush buffers and close the open file handle when the stream object goes out of scope. This adheres to the Resource Acquisition Is Initialization (RAII) idiom.

You only need to call file.close() explicitly if:

  • You want to reuse the stream object to open another file.
  • You want to release the file lock early before the containing scope terminates.
  • You want to immediately check if closing and flushing succeeded.

14.9 Binary File I/O

Text I/O converts in-memory binary values to ASCII/UTF-8 strings. In contrast, binary I/O reads and writes raw bytes directly between memory and the file, preserving exact representation without conversion overhead or rounding.

Always use std::ios::binary Omitting binary mode on Windows causes byte value 0x0A (\n) to be automatically expanded to 0x0D 0x0A (\r\n), corrupting binary data.

Writing and Reading Raw Data with write() and read()

#include <iostream>
#include <fstream>

int main() {
    int writeVal = 123456789;

    // Writing binary
    {
        std::ofstream out("data.bin", std::ios::binary);
        out.write(reinterpret_cast<const char*>(&writeVal), sizeof(writeVal));
    }

    // Reading binary
    int readVal = 0;
    {
        std::ifstream in("data.bin", std::ios::binary);
        in.read(reinterpret_cast<char*>(&readVal), sizeof(readVal));
        std::cout << "Bytes read: " << in.gcount() << "\n";
        std::cout << "Read value: " << readVal << "\n";
    }

    return 0;
}

in.gcount() returns the number of unformatted characters (bytes) extracted by the last unformatted read operation.

14.10 Struct Serialization to Binary Files

You can serialize entire struct objects to binary files in a single write() call, provided the struct is trivially copyable (POD — Plain Old Data):

  • The struct must contain fixed-size members (e.g. int, double, fixed char arrays char name[32]).
  • It must NOT contain heap-managing objects (like std::string or std::vector) or pointers, because writing them only dumps internal pointer addresses to disk, leading to dangling pointers and crashes on reload.
#include <iostream>
#include <fstream>
#include <cstring>

struct Record {
    int id;
    char name[32];
    double balance;
};

int main() {
    Record rec1{101, "Alice Smith", 4500.75};

    // Save struct to binary file
    std::ofstream out("records.dat", std::ios::binary);
    out.write(reinterpret_cast<const char*>(&rec1), sizeof(Record));
    out.close();

    // Read struct back from binary file
    Record rec2{};
    std::ifstream in("records.dat", std::ios::binary);
    in.read(reinterpret_cast<char*>(&rec2), sizeof(Record));

    std::cout << "Loaded: #" << rec2.id << " - " << rec2.name << " ($" << rec2.balance << ")\n";
    return 0;
}

14.11 CSV File Reading & Parsing

Comma-Separated Values (CSV) is the most widespread tabular text format. In C++, the canonical parsing technique combines std::getline(file, line) to read each row, followed by std::stringstream and std::getline(ss, cell, ',') to extract fields: 

#include <iostream>
#include <fstream>
#include <sstream>
#include <vector>
#include <string>

struct User {
    int id;
    std::string name;
    std::string email;
};

int main() {
    std::ifstream file("users.csv");
    if (!file) {
        std::cerr << "Cannot open users.csv\n";
        return 1;
    }

    std::string line;
    std::vector<User> users;

    // Read header line if present
    std::getline(file, line);

    while (std::getline(file, line)) {
        if (line.empty()) continue; // Skip empty rows

        std::stringstream ss(line);
        std::string idStr, name, email;

        if (std::getline(ss, idStr, ',') &&
            std::getline(ss, name, ',') &&
            std::getline(ss, email, ',')) {
            users.push_back({std::stoi(idStr), name, email});
        }
    }

    std::cout << "Loaded " << users.size() << " users.\n";
    for (const auto& u : users) {
        std::cout << u.id << " | " << u.name << " | " << u.email << "\n";
    }
    return 0;
}

14.12 Modern C++ File Operations: std::filesystem (C++17)

C++17 introduced the <filesystem> library, providing a standardized, portable interface for querying file paths, directory trees, file sizes, permissions, and filesystem metadata without platform-specific APIs.

Header #include <filesystem>
namespace fs = std::filesystem;

Essential Functions & Types

ComponentPurposeExample
fs::pathEncapsulates a filesystem path (handles OS separator differences)fs::path p = "data/logs/app.log";
fs::exists(p)Checks if a path existsif (fs::exists(p)) ...
fs::file_size(p)Returns file size in bytes as std::uintmax_tauto bytes = fs::file_size(p);
fs::create_directory(p)Creates a single directoryfs::create_directory("output");
fs::create_directories(p)Creates full directory path recursively (like mkdir -p)fs::create_directories("a/b/c");
fs::remove(p)Deletes a file or empty directoryfs::remove("temp.txt");
fs::directory_iteratorIterates non-recursively over files in a directoryfor (auto& e : fs::directory_iterator("."))
fs::recursive_directory_iteratorIterates recursively through subdirectoriesfor (auto& e : fs::recursive_directory_iterator("."))

Example: Directory Inspection with C++17 Filesystem

#include <iostream>
#include <filesystem>

namespace fs = std::filesystem;

int main() {
    fs::path dir = "./logs";

    if (!fs::exists(dir)) {
        fs::create_directories(dir);
        std::cout << "Created directory: " << dir << "\n";
    }

    std::cout << "Scanning current directory contents:\n";
    for (const auto& entry : fs::directory_iterator(".")) {
        std::cout << (entry.is_directory() ? "[DIR]  " : "[FILE] ")
                  << entry.path().filename().string();
        if (entry.is_regular_file()) {
            std::cout << " (" << entry.file_size() << " bytes)";
        }
        std::cout << "\n";
    }
    return 0;
}

14.13 Key Takeaways

  • Use std::ifstream for reading, std::ofstream for writing, and std::fstream for both.
  • Always check whether a file opened successfully using if (!file) or file.is_open().
  • Always loop over reads with while (std::getline(file, line)) or while (file >> token) — never test while (!file.eof()) before reading.
  • Use ios::binary when reading or writing raw byte buffers or structs to avoid OS newline conversions.
  • Binary structs must be trivially copyable — never write structs containing raw heap pointers or dynamic containers like std::string directly.
  • Stream pointers can be queried via tellg() / tellp() and repositioned with seekg() / seekp().
  • RAII ensures files are safely closed and flushed when stream objects exit their scope.
  • C++17 std::filesystem provides safe, cross-platform path querying, directory creation, and folder iteration.
