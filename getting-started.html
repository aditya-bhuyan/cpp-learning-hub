Getting Started — Compile & Run C++

Everything you need to install a C++ compiler and run programs from the command line — on Windows, macOS, and Linux.

Before you start All exercises and examples in this hub are plain .cpp source files. You write code in any text editor, compile it with a compiler on the command line, and run the resulting executable — no IDE required (though one is perfectly fine).

Linux — GCC / G++

Most Linux distributions ship with GCC (GNU Compiler Collection) or make it trivially installable. g++ is the C++ front-end of GCC.

Step 1 — Install GCC

Open a terminal and run the command for your distribution:

# Ubuntu / Debian / Linux Mint
sudo apt update && sudo apt install g++ build-essential

# Fedora / RHEL / CentOS
sudo dnf install g++ gcc-c++

# Arch Linux / Manjaro
sudo pacman -S gcc

# openSUSE
sudo zypper install gcc-c++

Step 2 — Verify the installation

g++ --version
# Expected output (version numbers will differ):
# g++ (Ubuntu 13.2.0-23ubuntu4) 13.2.0

Step 3 — Write your first program

Create a file called hello.cpp in any directory:

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}

Step 4 — Compile

g++ -std=c++17 -Wall -o hello hello.cpp
FlagMeaning
-std=c++17Use the C++17 language standard (use c++20 for modern features)
-WallEnable all common warnings — always use this
-WextraEnable extra warnings beyond -Wall (recommended)
-o helloName the output executable hello
hello.cppThe source file to compile

Step 5 — Run

./hello
# Output:
Hello, World!

Compile + Run in one line

g++ -std=c++17 -Wall -o hello hello.cpp && ./hello
Recommended: also use Clang on Linux sudo apt install clang installs clang++, which often gives clearer error messages than GCC. Use it exactly the same way: clang++ -std=c++17 -Wall -o hello hello.cpp

macOS — Clang (via Xcode Command Line Tools)

macOS ships with Clang (from the LLVM project) as its default C++ compiler. The g++ command on macOS is actually an alias for clang++. You install it through Apple's free Xcode Command Line Tools — no full Xcode needed.

Step 1 — Install Clang

Open Terminal (Spotlight → Terminal or Applications → Utilities → Terminal) and run:

xcode-select --install

A dialog will appear asking to install the Command Line Developer Tools. Click Install. This installs clang++, g++ (alias), make, and git.

Step 2 — Verify

clang++ --version
# Expected output:
# Apple clang version 15.0.0 (clang-1500.3.9.4)

g++ --version
# g++ is aliased to clang++ on macOS — same result

Step 3 — Write your first program

#include <iostream>
using namespace std;

int main() {
    cout << "Hello, World!" << endl;
    return 0;
}

Save as hello.cpp.

Step 4 — Compile

clang++ -std=c++17 -Wall -o hello hello.cpp
# or equivalently:
g++ -std=c++17 -Wall -o hello hello.cpp

Step 5 — Run

./hello
# Output:
Hello, World!

Optional: Install GCC via Homebrew

If you specifically need GCC (not just the Clang alias), install Homebrew first, then: 

# Install Homebrew (if not already installed)
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"

# Install GCC
brew install gcc

# GCC installs as g++-14 (version number may vary)
g++-14 --version
g++-14 -std=c++17 -Wall -o hello hello.cpp && ./hello
macOS tip — C++20 and modules Apple Clang lags slightly behind upstream Clang on some C++20 and C++23 features. If you need bleeding-edge standard support, use brew install llvm to get the latest upstream LLVM: /opt/homebrew/opt/llvm/bin/clang++ -std=c++20 ...

Windows — Three Options

Windows does not ship with a C++ compiler. Choose one of these three paths:

Option A — MSVC (Visual Studio Community) — Recommended for Windows

Microsoft's own compiler. Best Windows compatibility, full debugger, free for individuals.

  1. Download Visual Studio Community (free).
  2. During installation, select the workload: "Desktop development with C++".
  3. After installation, open the Developer Command Prompt for VS (search in Start menu — it sets up the correct PATH automatically).
REM Create hello.cpp with a text editor, then in Developer Command Prompt:
cl /std:c++17 /W4 /EHsc hello.cpp /Fe:hello.exe
hello.exe

REM Expected output:
Hello, World!
FlagMeaning
/std:c++17Use C++17 standard (use /std:c++20 for C++20)
/W4Warning level 4 (high)
/EHscEnable standard C++ exception handling
/Fe:hello.exeName the output executable

Option B — MinGW-w64 (GCC on Windows)

Brings the same g++ compiler you'd use on Linux, running natively on Windows. Good choice if you want identical commands across platforms.

  1. Download the installer from winlibs.com (choose the latest GCC release, UCRT runtime, 64-bit).
  2. Extract to a folder such as C:\mingw64\.
  3. Add C:\mingw64\bin to your system PATH:
    • Start → Search "Environment Variables" → "Edit the system environment variables"
    • Click Environment Variables → select Path under System variables → Edit → New → enter C:\mingw64\bin
  4. Open a new Command Prompt or PowerShell and verify:
g++ --version
# g++ (MinGW-W64...) 14.x.x

Compile and run exactly like Linux:

g++ -std=c++17 -Wall -o hello hello.cpp
hello.exe

# PowerShell: use .\hello.exe
.\hello.exe

Option C — WSL 2 (Windows Subsystem for Linux)

Run a real Linux environment inside Windows 10/11. Gives you the full Linux toolchain without a virtual machine — often the best developer experience on modern Windows.

  1. Open PowerShell as Administrator and run:
wsl --install
  1. Restart your machine. Ubuntu opens automatically on first launch.
  2. Inside the Ubuntu terminal, install GCC:
sudo apt update && sudo apt install g++ build-essential
  1. From this point, follow the Linux instructions exactly.
Recommended editor for Windows Visual Studio Code with the C/C++ extension (by Microsoft) gives syntax highlighting, IntelliSense, and integrated terminal on all three platforms — and it's free.

Universal Compile & Run Workflow

Regardless of OS, the daily workflow is the same three steps:

1️⃣
Write

Open a text editor (VS Code, Vim, Notepad++). Create program.cpp. Write valid C++ code with a main() function.

2️⃣
Compile

Run your compiler. Fix any errors (red output) or heed warnings (yellow). A successful compile produces an executable file.

3️⃣
Run

Execute the program. Observe the output. Go back to step 1 to improve the code.

Quick Reference — Compile Commands by Compiler

CompilerOSCompile commandRun command
g++ (GCC) Linux / WSL / MinGW g++ -std=c++17 -Wall -o prog prog.cpp ./prog  (Linux)
prog.exe  (Windows)
clang++ (LLVM) macOS / Linux clang++ -std=c++17 -Wall -o prog prog.cpp ./prog
cl (MSVC) Windows cl /std:c++17 /W4 /EHsc prog.cpp /Fe:prog.exe prog.exe

Reading Compiler Errors

Every error message follows the pattern: filename:line:column: error: description. Always fix errors top to bottom — one early error can cause a cascade of fake errors further down. 

# Example: missing semicolon
hello.cpp:5:5: error: expected ';' after return statement
    return 0
         ^
         ;

The compiler is pointing you exactly at line 5, column 5. Add the semicolon after return 0 and recompile.

Recommended Compiler Flags for Learning

# Full recommended flags for learning (Linux / macOS / MinGW)
g++ -std=c++17 -Wall -Wextra -Wpedantic -o program program.cpp

# For C++20 features (ranges, concepts, coroutines)
g++ -std=c++20 -Wall -Wextra -o program program.cpp

# With AddressSanitizer (detects memory bugs at runtime)
g++ -std=c++17 -Wall -g -fsanitize=address,undefined -o program program.cpp
FlagPurpose
-WallEnable all common warnings (use always)
-WextraExtra warnings: unused params, sign compare, etc.
-WpedanticWarn about code that doesn't conform to the ISO standard
-gInclude debug symbols (needed for debuggers and sanitizers)
-O2Enable level-2 optimizations (for performance testing)
-fsanitize=addressDetect buffer overflows and use-after-free at runtime
-fsanitize=undefinedDetect undefined behaviour at runtime

Zero-Install Options (Online Compilers)

If you can't install a compiler right now, use a free online compiler to follow along with every example and exercise:

Compiler Explorer (godbolt.org) Shows generated assembly; multiple compilers; great for optimization experiments
Wandbox Many GCC and Clang versions; stdin support; shareable links
cpp.sh Minimal and fast; good for quick snippets
Replit Full online IDE; file system; persistent projects
Ideone Simple; supports stdin; shareable
Recommendation for this hub Use VS Code + GCC (or Clang on macOS). Open a terminal inside VS Code (Ctrl+`), navigate to your file's directory, and use the compile commands shown above. You'll develop a muscle memory for the workflow that will serve you well throughout your entire programming career.
